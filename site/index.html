Compiler & toolchain

From C to an artifact

C is the active frontend. The historically named ide target is a headless compiler, test runner, benchmark driver, and metadata tool — not a graphical IDE.

Native application

Image browser & inspector

An explicit opt-in Linux x86-64/XCB application using the CPU rendering path. It does not depend on the compiler.

Shared components

Foundation & platform

Memory, strings, numeric helpers, and SIMD, alongside OS, file, and process services. These are shared components, not a separately packaged SDK.

Images & rendering

Media & graphics

Bounded in-memory image recognition, probing, and decoding, with separate graphics and UI components. The guides define each integration boundary.
