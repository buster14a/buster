The baseline is `69f594c81a52eb3457496d6c12761fda24ffce55`; the measured
implementation is `59b8fb74f351f404eef297d8829cb430d019c60d`.
This is a compiler-executable size result. Native runtime observations apply
only to this Linux/Ryzen 9 7940HS host; there is no Zen 5/9700X claim.

Five fixed-record A64 semantic payloads previously stored 1,270,200 base64
characters. Transposing blocks of up to 32 records by byte column and using
bounded literal/run packets reduces that to 347,492 characters plus 5,768
bytes of block offsets. Each block is base64-encoded separately, including
its own padding. Literal tags 0..127 carry 1..128 bytes; tags 128..255 repeat
the following byte 3..130 times. Semantic schema 2, record bytes/IDs, public
queries, JSONL/report bytes and original Arm provenance are unchanged.

Cold lookups fill disjoint portions of the existing decoded buffers through
a leaf-level once-claim. Publication uses the existing acquire/release
helpers; decoding makes no further claim or callback. Numeric readers
acquire a complete span once. Serial prewarm follows that same block path,
skips published blocks and publishes global readiness last. Temporary
descriptors take pure bounded reads. There is no thread-private production
memo or whole-table startup requirement for a cold query. The frontend,
including its retiring no-AST path, and x86 metadata are outside this change.

Both native Release subjects were built with trusted Clang 23.1.1, tests off,
unity on and identical normalized flags, including `-O3 -march=native`,
`-fwrapv -fno-strict-aliasing -funsigned-char`. Build roots differ; retained
compile commands and source/binary hashes make that boundary explicit.
Sizes use GNU `size`, `readelf -SW`, and copies stripped with
`strip --strip-all`; the original measured executables remain unchanged.

The full compile timing is inconclusive: there is no general compiler-speed
claim. Assembly probes are local improvements for those inputs; millisecond
startup observations are especially sensitive to process scheduling/timer
resolution and do not establish a general tiny-input speedup.

Rejected intermediates are retained as diagnostics. Per-byte packet scans
made the repeated assembly median 1.8135 s versus 0.1924 s baseline (12 pairs).
A single thread-private block memo reduced that to 0.2592 s versus 0.1941 s
(8 pairs), still unacceptable. Neither intermediate is shipped or claimed as
a qualified performance result; their uncommitted source states are not
reconstructible from a commit. The final once-published spans remove repeated
decoding and replacement; the final binary hashes and full raw comparisons
are authoritative for the accepted implementation.

Independent Python reconstruction compares every byte of all five payloads
with the preceding header, checks 385 deterministic pattern/width/boundary
cases, verifies header/JSONL/report hashes and reproduces the new header
exactly. The registered C regression uses original-payload FNV hashes,
malformed/bounded packet controls, final partial blocks, numeric spans across
blocks and short tails, invalid indices, concurrent cold publication and
prewarmed reads. Its temporary lane owner joins workers before later serial
prewarm. Four A64 objects and the frozen complete x86-64 linked artifact are
byte-identical between subjects; the latter SHA-256 is
`7fb7c979bccea30911990b438cea1b4acd64f8c7e95b086d1a326c8804eea2e4`.
