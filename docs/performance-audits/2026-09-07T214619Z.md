## Changes and limits

- `c_parse_index_scope_children` establishes token-interval ordering in the
  existing CSR child index. Already ordered siblings keep linear construction;
  other sibling lists use iterative merging with the completed cursor array as
  scratch. No additional index allocation or recursive traversal is introduced.
- `c_parse_scope_for_token` uses an upper-bound search for the containing child
  and iteratively descends. It retains the unindexed fallback for callers before
  the index exists. Disjoint sibling intervals, empty intervals, exclusive ends
  and equal-range nesting keep their previous semantic answers.
- Each aggregate initializer context remembers the occupied relocation extent
  and how many records it has indexed. Before a designated clear it incorporates
  only newly appended records. Disjoint ascending/descending clears skip the
  growing-prefix compaction; GNU range copies share their parent's index.
- Actual overlapping clears retain stable compaction and refresh the extent
  while visiting the surviving records. No relocation fields, ordering, addends
  or label provenance are rewritten by the fast path. Initializers without any
  relocations do not perform extent bookkeeping.

The relocation extent is conservative: clears into holes inside the extent and
arbitrary repeated overwrites retain the old full scan. This change removes the
demonstrated monotonic quadratic; it does not claim linear time for every possible
designator order. A general overwrite index would need to preserve both live
record capacity and stable output order; that storage change is deferred.

## Reproduction

From this repository root, after building the candidate Release compiler:

```sh
python3 tools/benchmark_frontend_scaling.py --baseline /path/to/pristine/ide --candidate build/Release/ide --out build/frontend-scaling --repetitions 5
```

The script generates each source once, runs both compilers on that exact path
with `-g0`, alternates execution order, and retains child CPU/wall samples,
source hashes and commands in `results.json`. Pointer-array cases run both
`-fsyntax-only` and object emission. Every object case requires byte-identical
A/B output. Source size, item count and timings are reported separately.

## Regression coverage

Registered frontend tests cover 4,096 reversed sibling intervals, 256 levels
of equal-range nesting, same-start empty siblings, invalid roots, exclusive ends
and agreement with the unindexed query on small trees. Relocation tests inspect
canonical bytes, target symbols, offsets, addends and unique occupied slots for
positional, ascending, descending, repeated, range, nested, erased and union
replacement initializers. Existing cleanup and computed-goto tests remain part
of the full suite.
