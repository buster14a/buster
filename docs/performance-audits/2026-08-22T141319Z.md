dispatches, marginal entropy 3,130 bits — but conditional entropy

the parent's resume, repeat — rediscovered dynamically per expression
through one BTB-limited indirect branch.  The same glue wraps it:
`EXPRESSION -> LOGICAL_VALUE -> EXPRESSION_CORE` and

merely forwards the child's result.  The children complete without

runs (1,4%), `PREPARE_CALLS` resumes 28.259 of 251.655.

The change: a push site whose child kind is statically known now runs the
child's first step directly and falls through inline when it completed; a
suspension leaves the child's continuation on the machine stack and resumes
through the loop unchanged, so the resumable shape is untouched.  Six

**The selector's dispatch is adjudicated against, with numbers.**  Census:
1.068.727 switch dispatches (plus 157.878 `fused_dead` rows that bypass
it); `CONSTANT_INTEGER` 21,0%, `LOAD` 19,3%, `STORE` 8,1%, `FIELD` 6,9%,
`CAST` 6,9%; marginal entropy 3,663 bits, `H(next|prev)` 2,359,
`P(next==prev)` 13,4% — run-grouping is dead, and a perfect first-order
predictor would reach only 40,5%.  Sorting or partitioning by class is not
available at all: every handler appends machine rows in program order
through shared selector state, so the emission order is the algorithm.  The
one classification the structure offers is positional — a lowered block's
last row is its terminator, and `BRANCH`/`BRANCH_IF`/`RETURN` cover 99,69%
of 113.978 block ends, leaving a 954.749-row body population at 3,382 bits
and a terminator population at 1,429.  Both spellings of that split were
built and measured against the merged tree, five alternated pairs each.
Splitting the loop with the ladder's default calling the full selector
outlines `machine_x64_select_instruction` (two call sites) and costs
**+32,1 M instructions (+0,32%), 0/5**, misses +136 K (2/5, noise).
Forcing it back inline (`BUSTER_INLINE`) duplicates the selector complex
and still costs **+21,5 M instructions (+0,22%), 0/5**, misses +217 K
(1/5).  The reason the miss column never moves is worth recording: the row
loop's exit branch retires immediately before every terminator dispatch, so
the indirect predictor's global history already carries exactly the signal
the split encodes — the entropy is in the opcode sequence itself, and at
13 cycles a miss the whole 429 K site is a ~5,6 M-cycle ceiling that
cannot pay for tens of millions of restructuring instructions.  Do not
retry this split, and treat opcode-peeling variants (`if (opcode ==
CONSTANT_INTEGER)` ahead of the switch) as the same trade: they add the
compare per row without adding information the predictor lacks.
