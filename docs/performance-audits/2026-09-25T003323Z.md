## Decision

No production change. The exact duplicate-check predicate ran **22,895 times**
while the frozen IDE translation unit was compiled; only **138 type-ID
comparisons** were performed across those calls. The largest accumulated work
queue had four entries. The two self-host generations produced identical
counts, preprocessed token/byte totals, and executable bytes. All five selected
repository C inputs compiled to byte-identical objects with the instrumented
and uninstrumented compiler; none had a duplicate comparison.

The observed population does not justify adding membership setup or metadata
to this hot caller. Retain the linear scan and close #1103 with this no-change
disposition. This concludes the issue's specified stop condition; it is not a
speedup claim.
