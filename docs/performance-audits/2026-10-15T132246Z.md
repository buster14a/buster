| Issue | Removed work | Primary population | Retired user instructions |

These are sequential parent-to-candidate increments on frozen binaries, not
additive savings. The combined result below was measured directly.

All use counts and local qualification remain live in #4290. Only the fields
whose consumers cannot run are omitted. The optional definition-ordinal/block
store observation in the original issue is outside this bounded repair.

For #4291, fusion's old register-map dependency is replaced by the same
prospective register-class rule that assignment uses. LOCAL promotion and
aligned-address exceptions are preserved. Copy-cast recognition already proves
a scalar result, and INDEX always produces an address register, so their fold
prepass needs no duplicate query. Classification still validates every result,
keeps canonical layout order, and omits only proven fused-dead scalar records.
The 332 optional alias-remapping records in the discovery census are unchanged.

For #4292, `built` alone does not authorize reuse: both return and argument
support must be complete. Partial/call-rejected variadic plans and absent
module contexts use fresh preparation. The definition-only aggregate expansion
bound is still checked even for a complete cached plan. Per-lane pools and
scratch-rewind ownership are unchanged.

For #4293, the valid one-block entry is block zero even with self-edges.
Multiblock layout keeps the original traversal. The shared helper's x86-64 and
AArch64 controls cover return, self-loop, duplicate self-targets and general
layout. CFG publication intentionally coalesces duplicate destinations.

### Rejected attempts retained

The first register candidate improved unity selector work by 1.687%, but added
redundant prospective queries to CAST/INDEX recognition and materially regressed
controls. The next candidate removed those queries and passed the indexed
primary (-3.713%), but arithmetic (+0.130%) and one-large (+0.109%) still failed
the declared screen. The accepted revision omits dead-bitmap reads when no
result was eliminated and keeps stable column bases across appends. Its full
control set passes. Failed and accepted receipts, source patches and binary
identities are all retained; unchanged measurements were not rerun to select a
green result.

Two fixture assumptions were corrected without changing production behavior:
the baseline CPU profile does not admit the test's 512-bit vector signature,
so the explicit cross-generation fixture now requests its CPU features; and
published CFG edges are unique even when a terminator names a destination
twice. Both old and new selectors agreed in the failed vector attempt. The
failed test logs remain in the archive. Rejected tool-argument probes (events
on `preflight`, and an abbreviated revision) are also retained; accepted
comparisons use the supported grammar and full source revisions.
