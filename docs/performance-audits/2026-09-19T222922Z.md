## Why this is not PMU qualification

The legacy capture did not retain the resolved `perf_event_attr` type/config for each alias, raw JSON rows, enabled time, running time, percentage/running fraction, or explicit unavailable/null observations. It also did not inventory optional IBS PMUs. Aggregate three-repeat medians are profiling diagnostics, not a powered paired counter experiment and not an instruction-count acceptance metric.

`tools/zen5_pmu_events_v1.json` now binds the raw AMD event select/unit-mask/config definitions to Linux's `amdzen5` tables. `tools/zen5_host_qualification.py` captures the missing actual-host facts and replays both successful and invalid records fail-closed. The old count table is retained as discovery evidence, not retroactively upgraded.
