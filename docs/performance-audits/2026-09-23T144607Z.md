## Decision

This is the current-main diagnostic rebaseline requested by #906. On the
single-translation-unit self-compile, **semantic analysis is now the largest
sampled user-space phase**: 29.49% of a weighted `cycles:u` profile, followed
by C-to-IR lowering (25.20%) and canonical code generation (25.13%). The
semantic `c_parse_validate_lowering_constraints` subtree alone contains 24.10%
of sampled user cycles. This is a research priority, not a case for removing
validation: #1028 owns a bounded attribution/reuse census. The next two
highest-information experiments are the function-duration/ownership screens in
#531 (lowering) and #54 (code generation). They are not approved parallel
implementations or throughput speedups.

The old September 11 phase percentages are not copied forward. In particular,
that capture put lowering at 47.14%; this source, input and profiler are
different, so the two shares cannot be subtracted to estimate an improvement.
No compiler production code, benchmark framework, or acceptance policy changes
in this audit. #36/#512 retirement and #511 remain separate.
