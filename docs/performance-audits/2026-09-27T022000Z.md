## Decision

Three identity domains are carried from where the compiler first establishes
them instead of being re-derived downstream. Each is a separate branch; all
three keep every output byte-identical. No timing claim is made; the evidence
is exact work counts from a disposable census.

## Method

The census is the anchor-checked script `identity_census_apply.py` with
`identity_census.{h,c}` in this audit's evidence directory. It is applied to a
tree, never committed to production code, and built with
`-DBUSTER_IDENTITY_CENSUS=1`. It counts `string_equal` calls and the bytes each
compares; `buster_hash_64` and FNV-1a calls and bytes; `c_symbol_intern` calls,
key bytes, probes, middle compares and insertions; `c_symbol_find` probes; and
type-compatibility calls, self-comparisons, pair-stack allocations and bytes,
and pairs visited. Records are keyed by driver-marked phase and by the two
innermost return addresses of the counted routine, made `noinline` in the census
build and symbolized with `addr2line`, so every count is attributed to its call
site. The same script is applied to `main` and to each candidate
(`--lenient` skips only the `c_symbol_find` anchor a tree lacks).

`census_report.py` summarizes and symbolizes one run, `census_compare.py`
joins two runs by phase, kind and tag, and `corpus_diff.py` compiles every
`tests/*.c` fixture with two compilers under eight configurations and compares
exit status, diagnostics and output SHA-256. `census-comparison.txt` holds the
three full comparisons and `census-baseline-sites.txt` the baseline's top call
sites.

## Findings behind each domain

**Identifiers.** The preprocessor interns every lexed identifier once
(833,192 interns, 34,716 ids). Three leaks made later phases re-derive the
identity:

- a `##` paste left its identifier's symbol 0, so every later lookup
  re-interned it and dropped the answer;
- entity and typedef lookups ran on punctuator, number and literal tokens in
  type-specifier position, which interned those spellings as names: 171,604
  interns and 5,937 insertions, from 45,562 punctuators, 24,250 string
  literals, 15,963 numbers and 27 character literals (a diagnostic print
  counted every zero-id lookup; no identifier was among them);
- declarations, members, enumerators and lowering's function-name index keyed
  on spellings: 12,018 declaration re-interns, 2,293,627 member-name compares
  (3,733,267 bytes), 4,205,584 enumerator-name compares, and 68,065 whole-name
  hashes plus 8,873 re-interns in lowering.

**Program symbols.** Codegen names every relocation target by `IrSymbolId`,
but the object writer mapped only function entries by it. Globals and aliases
(15,434 first references), DWARF `DW_OP_addr` (15,348 lookups; the
`DwarfRelocation.symbol` field existed but was never set) and CodeView
`S_GDATA32` (a second index built per object) all re-derived the target from
the link name, and a new extern hashed its name twice. The 20,553-hash index
build, one per definition, remains: extern link names may match definitions or
each other.

**Types.** `c_parse_types_compatible` ran 108,554 times; 105,088 compared one
id with itself (STRUCT 90,094; CHAR 7,183; UINT 3,873; UCHAR 1,946; ULONG
1,345; ENUM 265; others below 150; FUNCTION 15). Each allocated a pair stack of
`2 x type_count + 1` entries and walked the structure. The walk is not
unconditionally reflexive (an out-of-range id or array-bound record is
incompatible) and has a side effect (a qualified aggregate without its
unqualified link gains a row per `c_parse_unqualified_type` call), so the
chain that replaces it reproduces both.

## Dispositions

Owned elsewhere, counts recorded here as evidence: `ir_call_returns_twice`
(571,130 `string_equal` in lowering, #1431); x86 metadata form hashing in
codegen (29,580 hashes, #1295, #1317); pair-stack sizing for distinct-id walks
(#1502); tag lookup (#1467), LLVM constant pool (#1499), Wasm rescans (#1458),
eBPF call targets (#1500), debug seeds (#1447), `.s` interning (#1319).

Next candidates, measured after the identifier branch: keyword predicates on
tokens that already carry predefined ids (`c_parse_alignof_word` 3,972,123
calls; asm validation 1,931,070; expression leaves 1,813,240; lowering
constraints 1,207,776; `c_ir_math_builtin_link_name` 569,984), lowering's IR
field-name lookup (2,244,700 compares, 2,004,642 bytes), and the DWARF legacy
builder's discarded `.debug_str` interning (5,205 hashes).

Rejected: a universal interner; structural interning of `CType` (array bounds
are token ranges, tags are scoped, declarator types are deliberately
independent); merging IR function, array or vector types (one debug record per
`IrTypeId`); string-literal merging (changes generated programs); removing the
object name index or the linker's cross-object name resolution (both are the
exact link-name semantics).
