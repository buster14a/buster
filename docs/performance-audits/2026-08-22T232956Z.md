- **The mechanism was built anyway, and it fires.** QUALITY's candidacy admits
  vector-class values; the pin file gains a vector segment behind the general
  one (highest register first, so the pins collide last with the local scan's

  foreclose the whole caller-saved vector file; the vector class carries its
  own budget and depth arrays. With it in, the three vector edits in
  `machine_fast_free_candidates` **disappear** — the probe's census line for
  that function is gone — and the emitted object shrinks by 16 bytes. Nothing
  else in the workload changes.

- **Where the cost actually came from, which is worth more than the verdict.**
  The first build measured `+49,075,124` (`+0.398%`) and three rounds of
  restructuring walked that down to `+17.1M` without changing what the pass
  computes. Each step is a rule about adding a rarely-taken feature to a pass
  that runs over every function:
  - `+49.1M -> +31.8M`: the vector foreclosure and budget rows were folded into
    the walk that computes the general ones, putting a per-operand class test
    and a per-instruction branch on the path all 3,865 functions take. Moving
    them to a **second pass gated on the function having admitted a vector
    candidate** — a pass that runs for one function in the workload — recovered
    `17.3M`.
  - `+31.8M -> +18.4M`: candidacy computed the class facts eagerly, ahead of
    the `disqualified` / `interval_starts` / `baseline_traffic < 3` rejections.
    Nearly every virtual register dies on one of those three, and hoisting the
    class test above them made each one pay a strided load out of the
    virtual-register table for an answer it discarded. **Restoring the original
    short-circuit order recovered `13.4M`** — from a change that computed the
    same answer.
  - `+18.4M -> +17.1M`: the interval struct had grown 20 -> 24 bytes for one
    flag, and the heap sift copies it three times per level on every pop.
    Packing both flags as `u16` restored twenty bytes and recovered `1.3M`.
    Spelling the two budget walks apart instead of selecting the arrays through
    a pointer measured `+19.2M`, i.e. **worse** than the pointer it replaced, so
    that one was reverted — the indirection was never the cost.
  The residual `+17.1M` is the irreducible remainder: per-surviving-candidate
  class work and per-pop file bounds in a pass that walks every function and
  every candidate. **The rule generalizes past this lever: a feature whose
  population is one function pays for itself across all 3,865 unless every
  statement it adds is behind a gate the other 3,864 evaluate once.**
