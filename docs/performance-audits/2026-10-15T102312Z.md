## Mechanisms and safety boundaries

**QUALITY.** `machine_fast_placement_scan_prepassed` produces the operand/edit
plan. Only a plan whose weighted traffic improves and whose pins verify runs
`machine_fast_placement_finish`. Rejections rewind the caller arena to the
probe mark; the baseline and scratch-owned prepass remain live. Baseline frame
capacity is checked before candidates, and a candidate capacity refusal keeps
the original retry/fallback policy. Public prepassed placement still returns a
completed frame. The scan has one shared exit, with explicit stale/invalid
prepass refusal controls.

The current-source diagnostic sees 6,742 QUALITY invocations, including
scheduling replays, and 3,934 probes. There are 2,335 accepted placements,
440 traffic rejections and 1,159 pin-verification rejections. Frame
constructions fall from the old call-site model's 10,676 to 9,077: 1,599 rejected
frames are omitted. Rejected scans reclaim **136,336,604 cumulative logical
arena bytes**. This is neither peak RSS nor released physical pages.
The existing 4,096-unused-ID replay retains 144,774 bytes, versus baseline
289,710, with zero accepted pins. The regression reconstructs the baseline
independently, bounds retained state to it and allocates over reclaimed probe
storage before checking encoding on six desktop targets and both frontend forms.

**Sorting.** Ordered streams move no records; fewer than 256 unsorted records
use stable ping-pong merges. Larger streams use stable byte radix passes over
only differing key bytes. Every pass moves the complete 16-byte `MachineEdit`;
equal-point repair order and the final main-before-retroactive merge remain
unchanged. The 256 threshold was fixed before measurement, not tuned to results.

| Real unity population | FAST | QUALITY |
| --- | ---: | ---: |
| Sort calls / edits | 4,840 / 91,351 | 8,470 / 253,449 |
| Largest stream | 2,849 | 4,007 |
| Already ordered calls | 2,741 | 4,277 |
| Radix calls | 29 | 128 |
| Reference record moves | 1,161,878 | 3,725,060 |
| Recorded candidate moves | 428,574 | 1,153,440 |
| Record-move reduction | 63.11% | 69.04% |

Reference moves are reconstructed per actual call as
`2 * count * ceil(log2(count))`, exactly the old merge implementation's copying
work, rather than measured baseline retired instructions. The independent
insertion oracle checks empty/singleton, duplicate/full-width keys, complete
payloads, 255/256/257 and guard bytes. Extracted old/new kernels additionally
match under Clang, GCC and ASan/UBSan, including 262,144-record streams.

**Empty pools.** The existing eligibility walk supplies separate scalar/vector
counts. FAST records 3,851 omitted empty histograms over 282,654 instruction
rows, corresponding to 1,176,828 old logical request bytes. QUALITY records
4,972 over 456,309 rows, corresponding to 1,884,900 bytes, on its candidate
frame-invocation population after deferred rejection. No extra census pass is
added. Positive pools retain their old order, widths, colors and offsets.
This does not revive #1912's previously rejected combined-ordering design.

**Known-failing home coloring.** After exact liveness converges, a common
occupied block proves that all homes in either pool form a clique. Every new
home must then compare with every earlier group. A histogram of each home's
first occupied block word supplies a lower bound on those comparisons; only
when it exceeds the existing 25 M budget is the occupancy transpose and greedy
scan skipped. Every formerly successful coloring is preserved. The conservative
upper bound is used only to avoid running this proof on small populations.
The depth-2,000 reproduction has 1,999 homes, 8,002 blocks and 32 home words;
the proof triggers, and recorded coloring comparisons are zero. This is a
sufficient certificate for this population, not a new universal graph-coloring
algorithm; unproved populations retain the existing bounded fallback.

The first conservative upper-bound admission prototype was **rejected**:
it skipped one successful frozen-unity coloring, adding 912 aggregate frame
bytes and 11 symbol bytes to `c_lower_to_ir_reserved_run`. Its binary/cache,
metrics, hashes and symbol diff remain in the evidence. The replacement never
uses an upper bound as proof of failure. Negative controls cover separate
pools, missing common blocks, padding bits and cheap early conflicts.
