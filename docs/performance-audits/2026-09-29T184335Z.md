## Decision and scope

Replace writer-by-writer body searches and per-hit prefix scans with one
source-order walk per body. Carry the existing 256-entry architecture stack,
parent restoration and `else` inversion; test all writer spellings at identifier
boundaries. Unknown contexts retain the old statement/ternary look-back.
No source-authority checks, writer spellings, consumer/neutral registries,
production compiler behavior, or generated authority bindings change.

This removes repeated brace-prefix discovery. It does not claim linear time
for arbitrary unknown-context expressions: the retained statement look-back
and ternary colon search can still revisit a large statement.
