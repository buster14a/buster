## Change and correctness boundaries

Previously each complete census opened, read to EOF, parsed, and closed the
stat file of every enumerated system task, including unrelated user tasks
and kernel tasks. Cleanup requires two matching snapshots and is repeated
throughout this process-heavy test workload.
One native-run inventory contained 557 procfs entries, including 285 in
group zero. The benefit depends on the process-table population and the
workload's cleanup frequency; it is not a prediction for a smaller CI host.

`os_linux_process_group_stat_at` now first queries `getpgid` only when the
already validated procfs context has one namespace coordinate and selects
coordinate zero. A successful different group, including group zero, is
enough to exclude an unrelated task from that snapshot. A matching group or
failed query still performs the existing stat read. Ancestor-mounted procfs
uses the original path for every PID. No membership is cached across
snapshots. Member state, namespace identity, two complete matching censuses,
and the final exact-child ownership/reservation check remain unchanged.

The syscall returns a process group in the caller's PID namespace, while
`NSpid` lists coordinates starting with the procfs mount's namespace. This
is why the optimization must not run against ancestor-coordinate PIDs.
See the primary references for
[getpgid](https://man7.org/linux/man-pages/man2/getpgid.2.html),
[proc PID status](https://man7.org/linux/man-pages/man5/proc_pid_status.5.html),
and Linux's
[do_getpgid implementation](https://github.com/torvalds/linux/blob/master/kernel/sys.c).
Errors do not become evidence of absence; they take the old read/error path.

The focused regression uses a valid non-directory descriptor to distinguish
the permitted exclusion from paths that must read stat. It covers the
same coordinate, ancestor/invalid coordinates, a matching group, and a
failed `getpgid`. Existing live-member, zombie, descendant, ownership-loss,
and churn controls remain active. The new test also accepts a namespace
init whose inherited process group is outside its visible namespace and
therefore appears as zero.
