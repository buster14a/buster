## Workload

Every arm compiles the same input, the base revision's unity self-host source,
from the base checkout:

```sh
ide cc -Isrc -Ibuild/v3/generated -DBUSTER_UNITY_BUILD=1 -DBUSTER_INCLUDE_TESTS=0 \
  -target x86_64-unknown-linux -march=znver5 -g0 -fsyntax-only \
  [-fc-ast-pilot] src/buster/apps/ide/ide.c
```

4,059,018 tokens reach the parser, and the tree has 2,685,032 nodes. Four arms:
- A: base, default flags;
- B: base with `-fc-ast-pilot`, which builds the tree and does nothing else with it;
- C: candidate with `-fc-ast-pilot`, where semantic validation also answers
  expression-type queries from the tree;
- D: candidate, default flags.

B − A is the tree's cost, C − B is the typer's effect, C − A is the
end-to-end effect of turning the pilot on, and D − A is the cost to the
default path. Callgrind ran with `--cache-sim=no --branch-sim=no`.

## Reading

- With the tree built, the typer pays for itself: 2.1% of the compile's
  instructions.
- The tree costs 4.4%, so turning the pilot on is still a net loss of 2.2%.
- Stage 1 answers bound names, literals, member access, subscripts,
  dereferences and named calls. These are the cheap queries.
- The expensive machine runs that remain (335 K at about 3,180 Ir each) are
  ranges whose root is an operator, a cast or an assignment.
- With the tree's build cost unchanged, closing the gap needs both:
  - stage 2 kinds that remove those runs;
  - a cheaper eager pass, which today costs about 150 Ir per typed expression
    node.

## Validation and limits

- Callgrind counts instructions, not time, on `-march=x86-64-v3` builds whose
  AVX-512 kernels are compiled out; architecture-neutral deltas transfer.
- One input, one host, single process, no pinning and no `perf` counters.
- The 9700X pull-request comparison runs default flags only. It can compare
  arm D against A, but cannot time the hook. Zen 5 validation of the typer
  therefore stays **incomplete**.
- Correctness of the measured candidate is covered by `c_ast_tests` and
  `compiler_driver_tests`, including the corpus verify gate, in the pull
  request that carries this audit.
