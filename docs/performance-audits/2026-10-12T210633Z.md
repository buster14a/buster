## The candidate and its variants

The candidate reads a root run whose `DECL_SPECIFIERS` list is plain words,
then one `STRUCT_`, `UNION_` or `ENUM_SPECIFIER` holding only its `TAG_NAME`,
last. It makes the frames' calls in their order:
1. `c_parse_type_identity_prepare`;
2. `c_parse_tag_lookup` in the run's scope, with the standalone block-scope
   declaration's fresh identity;
3. `c_parse_add_type` when no tag is visible;
4. the scalar frame's `c_parse_add_qualified_type` when a `const` or
   `volatile` word asks for a qualifier.

A tag of another kind goes to the machine under a new `tag` reason.

## Decision

**Negative.** The gate needed C − B of at least −5 M. The best of six
layouts reached −2.54 M, and one rose by 1.80 M.

The work a read can remove is real: about 6.9 M of machine self cost
disappears. But every layout tried pays 4.4 M or more back in code generation
around the 124,934 plain reads and the index pass, which the 1,333 tag reads
cannot repay. No code ships. The base's machine stays the path for these
runs.

## Negative and unproven parts

- **Not tried:** a layout that charges nothing to the plain read and the index
  pass, such as a tag index built only when the first `input` fallback
  arrives. Building it needs a pass over the tree's kinds, about 3.6 M at the
  index's eight-node rate, which is above the margin.
- **Correctness was not established:** no verify mode, model differential or
  `test_all` ran on the variants. Only the counters and the object identity
  above were checked.
- **Tag definitions** (499 runs, 9.91 M) were not split between body and
  frame. The estimate of 3 M outside the body is an upper bound by analogy,
  not a measurement.

## Validation and limits

- Callgrind counts instructions, not time, on `-march=x86-64-v3` builds whose
  AVX-512 kernels are compiled out. One input, one host, single process.
- The census classifier and the variants are instruments, not reviewed code.
- No 9700X comparison is requested. Zen 5 validation stays **incomplete**
  (#2761), and the pilot-default switch stays on hold.
