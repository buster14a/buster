## Mechanisms and contracts

- Aggregate constructors check field range/type once. Increasing field IDs
  prove uniqueness without allocation; arbitrary order uses one bit per field.
  The complete nonempty struct population is bounded by the 16-bit immediate
  count. Operand order, union/zero-size handling and exact error context remain.
- CAST and INDIRECT_BRANCH validate set shape/uniqueness once, then use one
  immutable sorted-view subset query. Equal cardinalities and uniqueness prove
  equality, replacing all-pairs membership and validating contains-per-member.
- Small splice proofs retain marker bytes only for recorded old IDs and the new
  suffix. Old IDs use immutable radix-sorted indexes; absence implicitly means
  owned/parameter-defined. Dense prefixes are chosen only when their size is
  at most four times the old region. The pre-existing capture scan also records
  original parameter-bearing blocks, so the proof need not rediscover them
  across every old block. Predecessor rebuilding itself still scans the CFG;
  this is a regional validation claim, not a regional entire-inliner claim.
- Dense full walks retain direct byte indexing. Distinct successful row and
  parameter claims count checked values, allowing a complete-definition success
  to skip the orphan-marker sweep. Unclaimed values, including permitted aliases
  of an existing definition, still use the original sweep. Sparse proofs retain
  their function-pointer-result refusal and the independent strict fallback.

The standalone diagnostic calls unchanged production entry points on valid,
fully backed canonical IR. The splice setup first obtains a full valid verdict,
then snapshots counters before checking a fixed one-row region. It does not
execute an inline transformation; registered inliner controls separately cover
real splices, rewritten incoming lists and planted faults.
