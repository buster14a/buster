The full Debug suite covers all 16 pass subsets structurally, existing

and preallocation budget refusal. Its integrated driver coverage executes

Additional diagnostic replays execute all 16 subsets through Node 24 Wasm64
and Clang 18-linked LLVM bitcode. Wasm tests exercise eight argument pairs,
including 64-bit unsigned wraparound; LLVM executes the same fixed-answer
fixture as native code. These are correctness replays, not benchmarks.

Still required before default adoption: final-head hosted platform/sanitizer
checks, the wider standard mode-matrix gate, and the frozen six-workload paired
end-to-end compile-time/peak-RSS series, including each pass independently
disabled, on an exclusive qualified host with an A/A noise control. The
pipeline remains opt-in and #40 remains open for that acceptance. No speedup,
performance equivalence, physical Zen 5 result, or completed issue is claimed.
