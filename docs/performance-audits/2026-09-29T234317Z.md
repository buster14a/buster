## Question and missing guarantee

Hypothesis H1: a bounded independent value analysis can validate a useful
allocation subset and detect placement corruption that the existing MIR verifier
cannot observe. Stop if correct real placements cannot be proved, or any
deliberately corrupted supported placement validates. The executed scalar
fixtures support H1 within their stated boundary; they do not establish corpus
coverage.

Hypothesis H2: a block-invariant certificate can reduce checking work enough to
justify producer/payload complexity. The observation-only experiment counts N
rather than 2N transfers and measures a lower diagnostic cost, but has no joins,
spills or certificate-production cost. H2 remains unestablished for Buster;
there is no evidence yet for a production certificate format.

Buster can check allocation dataflow independently of the allocator's placement
algorithm. The useful guarantee is that every admitted allocated use has the
current logical value required by its corresponding pre-allocation use, and
that the specified return observation has that value. This is stronger than
checking register interference or legal operand shapes.

Observed source facts: `machine_verify_function` verifies MIR storage, operand
kinds/classes, definitions, dominance and edge source validity. Production
`codegen.c` calls it for untrusted selection or requested invariant checking;
fresh selector-certified MIR normally bypasses that scan. Its two verification
calls precede placement. The allocated result is the unchanged MIR row array,
four assigned registers per row and the point-sorted `MachineEdit` stream.
`placement.valid` then authorizes encoding. QUALITY's `pins_hold` is a narrower
pin-ownership check. None of these proves that a reload/copy or allocated use
contains its intended reaching value.

The source census found four public placement-builder call sites in codegen
(three initial modes plus scheduled QUALITY), two native encoding call sites,
and 302 target opcodes: 172 x64 and 130 AArch64. The real adapter admits only
four x64 opcodes under restricted shapes. This is a vocabulary count, not a
runtime coverage fraction or whole-compiler cost estimate.

## Model and transfer system

Let `A[l]` be a finite set of logical names known to equal the full contents of
physical location `l`. Membership is a must fact over all executions reaching
the point. The initial prototype represents each set with one `u64`; unknown
is the empty set. Resources are whole 64-bit GPRs and actual eight-byte frame
ranges, not allocator spill-home IDs. Overlapping stack writes invalidate the
whole fact for every overlapping represented range, safely losing coverage
for partial overlap.

* A move, spill or reload snapshots source facts, kills overlapping destination
  facts, then installs the snapshot. An edit never asserts a logical identity
  merely because its allocator subject says that identity.
* At a matched source instruction, every use must have its specified symbol at
  its allocated location. Fixed, tied and early-clobber constraints are checked
  independently. Definitions remove the overwritten symbol from **every**
  location, including old spill copies, before establishing the result.
  This kill matters even for SSA because a static definition executes again in
  a loop. Source copies retain justified name equivalences.
* Independently specified call clobbers kill architectural resources. Calls in
  the real Buster adapter are currently unsupported; generic call fixtures test
  only the logic under an explicit frozen ABI contract.
* Rematerialization requires a checked immutable source constant recipe and
  matching literal/width. It cannot import an arbitrary asserted identity.
* An edge first executes its actual sequential physical edits. Logical block
  parameter assignment then uses a snapshot: remove all destination parameter
  names and add each destination wherever its old source name occurred. This
  substitution is simultaneous, including cycles and repeated sources.
* Joins intersect corresponding facts after each incoming edge transfer.

A separate must-availability bitset records which logical definitions have executed; rematerialization does not require a surviving physical copy.

The solver initializes reachable nonentry blocks optimistically and descends
through finite must-state intersections. Reachability is distinct from empty
knowledge. It checks uses only after convergence. Its explicit sweep ceiling is `1 + B*(L+1)*S`, at most 266,241 under the prototype caps, because every changing sweep removes an entry fact. Exceeding that proof bound returns inconclusive coverage rather than success; it is not a production latency budget. A certificate mode instead checks
the entry boundary, transfers from every reachable claimed block state, all
uses and every edge implication to its successor's claimed state. Certificates
are untrusted invariants, not instruction semantics. Missing, wrong-version,
wrong-sized, contradictory or noninductive certificates cannot validate.

The prototype bounds symbols, locations and blocks at 64, original rows and
edits at 4,096, and edges at 256. Capacity overflow is explicit unsupported
coverage. These are research bounds, not proposed production limits.

## Preservation obligations and coverage

| Obligation | Initial treatment / remaining work |
|---|---|
| Reaching values | Check each corresponding operand against must-equality facts; never trust allocator owners, intervals, last-use or pins. |
| Parallel edge copies | Generic model supports simultaneous parameter substitution and sequential emitted copies; real adapter is single-block. Emitted branch/edge binding remains to be implemented. |
| Spills/reloads | Key actual frame ranges; clear overlaps; check transfer order and bounds. Real adapter checks BEFORE/AFTER phases and rejects unconsumed or unemitted edits. |
| Calls | Generic kill tests under frozen ABI masks; real calls unsupported. Later independently derive argument/result and caller-clobber units for each ABI, including partial vector preservation. |
| Tied/fixed/early operands | Full-width constraints checked; initial x64 ADD tie and RAX result are independently specified in adapter. |
| Partial GPRs | Unsupported. Later model W/X and x86 subregister writes, upper-bit zeroing, high-byte restrictions and read footprints. Coarse invalidation can be safe but less complete. |
| Vector/mask aliases | Unsupported. Later model XMM/YMM/ZMM and NEON overlapping byte units, predicate widths, implicit scratch and target call preservation. Different names do not imply independent resources. |
| Stack-slot lifetimes | Actual content tracking exposes overwritten live homes without trusting coloring lifetimes. Arbitrary source stack objects, escaping addresses, outgoing arguments, dynamic frames and returns-twice entry are outside initial scope. |
| Callee saves | Adapter excludes reconstructed SysV save-area bytes from private spill ranges. It does not prove prologue/epilogue preservation or their encoding. |

Preflight currently reports even an unsupported instruction in an unreachable block as `UNCOVERED`; value checks are restricted to entry-reachable execution. A concrete correct copy-alias fixture returns `NOT_PROVEN`: a new COPY name is added only at its destination, so another existing equal physical copy is not recognized. This is a demonstrated conservative precision limit.

Only `VALID` means successful validation. `INVALID` reports malformed or illegal
structural output; `NOT_PROVEN` reports a required symbolic equality missing
from conservative analysis; `UNCOVERED` reports an unsupported semantic feature
or capacity; `CERTIFICATE_REJECTED` reports absent/malformed/insufficient proof.
Failure to prove equality is not, by itself, a theorem of concrete inequivalence.

## Trusted boundary and soundness argument

The trusted input is an immutable, already verified pre-allocation function,
its CFG and ABI entry/return contract; the correspondence extraction and the
small independently audited semantic whitelist; and the checker implementation
and its C execution environment. Allocation output and certificate facts are
untrusted. The real adapter freezes instructions, virtual registers, immediates and blocks before invoking any allocator. Exact count/byte comparisons reject source mutation. It reads `operand_registers` and every actual edit, reconstructs frame addresses and dispatches independently on the frozen opcode. Allocated body opcodes are bound by unchanged actual MIR; encoded bytes remain outside the proof. It does
not reuse FAST's compact opcode/prepass facts, allocator liveness, pin tables,
home liveness or selector absence certificates as value proofs.

For every state membership, assume the physical bytes equal the current source
name. Correct entry facts establish this invariant. Checked equal inputs to the
same matched operation justify an equal result; copy transport preserves equal
contents; definition and overlap kills remove obsolete facts. Intersection
retains only common facts. Simultaneous substitution renames the source values
on an edge without assuming that its physical copies were correct. A converged
invariant, or a checked inductive certificate, therefore extends the argument
through any number of loop iterations. All admitted use observations follow.
This is a written proof argument under the explicit model, not a mechanically verified implementation theorem. The typed-array API assumes readable buffers of the declared extents; no serialized certificate parser exists. Null/count/version rejection is tested, but inaccessible-pointer or truncated-byte-buffer safety is not claimed.

The generic model does not decode machine bytes or represent a separate
post-emission CFG. The real adapter currently admits only one block, so it
cannot authenticate branch targets. It does not validate instruction selection,
scheduling semantics, ABI classification, arbitrary memory behavior, unwind,
relocation, encoding or whole-machine-code correctness.

## Independent attacks and experiment contract

The cheapest discriminating experiment was to keep a structurally verified MIR
function unchanged and mutate only its placement. A structural verifier can
still accept that MIR while an independent value checker rejects the wrong
allocated use or overlapping live home. This tests the genuinely missing seam
without first modifying the allocator.

Absolute expected outcomes and hand-written certificates are authored separately
from the checker. Concrete path witnesses for destructive copies and stale loop
spills use direct scalar execution rather than the checker's symbol transfer.
Checking solver-produced entries as a certificate is merely a consistency test;
it is not counted as independence evidence.

The experiment keeps all outcomes, including expected unsupported fixtures and
failed attempts. Checking cost uses prebuilt inputs, one warmup and seven samples
on a standard GitHub runner; construction, compiler building and output printing
are outside the measured interval. It counts transfers/edits/edges/sweeps. These
microseconds are diagnostic checker cost, not whole-compiler overhead, a speedup
or dedicated-9700X acceptance evidence.

## Disposition and smallest implementation packet

Go for a test-only scalar checker and a bounded extension of its actual-output
adapter. No-go for production admission, broad coverage claims or a new
production certificate payload yet. The strongest counterargument is a common
semantic mistake shared by the trusted extraction/table and the allocator:
an independent dataflow algorithm alone does not eliminate that risk. Audit
those small tables against architectural semantics and test their concrete
effects separately.

The smallest useful next packet is: register an optional test seam using the
existing verifier; bind two-block branch/edge output and parallel parameters to
the actual Buster placement stream; add independent absolute cycle/loop cases;
preserve distinct proof/coverage outcomes and bounded scratch; census covered
functions, rows, edits and unsupported reasons on a fixed corpus. Measure extraction and size-acknowledge the retained diagnostic code. Only then
price the seam and any certificate alternative on benchpress 9700X. Keep it
outside default production compilation and admission policy.

Uncertainty: the scalar fixtures do not establish whole-corpus coverage or
whole-compiler overhead. The dedicated benchpress 9700X execution environment
was unavailable in this session; the existing maintainer-only service authority
was preserved. Native Windows/AArch64 and vector/mask validation remain unrun.
