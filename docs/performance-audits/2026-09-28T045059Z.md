## Decision

Three collection-time lookups in `src/buster/lib/compiler/llvm/bitcode.c`
scanned a growing array for each new row, so each was quadratic over a module:

- `llvm_bc_add_constant` compared each constant with the whole pool;
- `llvm_bc_name_available` compared each new global, function, import and
  synthetic intrinsic with every entity collected so far;
- `llvm_bc_find_integer_count` scanned every function for each ctlz, cttz and
  ctpop instruction, during both collection and emission.

The pool is now indexed by an open-addressed hash of (type ID, code, operands),
stored as `constant_slots`. Link names use the `name_slots` hash index, and each
entity is registered as it is appended. Integer-count declarations are held in a
fixed `integer_count_functions[operation][width]` table. The indexes only locate
rows. Pool order, entity order, value IDs and the emitted bytes are unchanged.
Name lookup keeps the old rule: a name is unavailable when any entity with that
name has a different symbol.

## Identities and method

- Base: main `76a7bdd377e8769ebbb98d1cc178561b8d88c1a6`. Candidate: branch
  `claude/admiring-albattani-vb6ce4` at the commit that adds this audit.
- Builds: a Clang 18.1.3 Release tree. The `build.c` driver itself was
  Clang-built as in the hosted CI, because this container has no TCC. That makes
  this build untrusted, so it is used here only for measurement.
- Instruction counts come from callgrind (valgrind 3.22.0), run on the
  `profiling_build.py` twin of each tree (`-march=x86-64-v3`, tests off). The
  twin script is in the #1459 evidence directory
  `docs/performance-audits/evidence/2026-09-26T150516Z/`.
- Inputs:
  - `fact_flow_ab.py generate --sizes 4000 16000` (sN, from the same #1459
    evidence directory);
  - `pcN.c`: N functions, each
    `int fI(unsigned x){return __builtin_popcount(x)+__builtin_ctz(x|1)+__builtin_clz(x|1);}`.
- Command: `ide cc -emit-llvm -c <input> -o <output>`.
- Seconds are single wall-clock runs of the ordinary Release binaries and are
  indicative only.
