These categories are not additive. OS requests are not measurements of resident
or physical committed pages; reserved address space is not RSS. Arena totals
are cumulative requests, not live or retained scratch. The zero counters cover
only the zeroed arena API, not explicit `memset`, loader/OS zeroing, or all bytes
cleared by the compiler. The large case's top logical requests include

no inference of unnecessary semantics follows from their presence.

## Design and focused regression

An active undo record for a symbol implies a valid current binding: binding
installs one, and unwind removes the record before restoring its predecessor.
A previously unbound symbol therefore cannot occur in the active undo log.
`c_parse_binding_bind` checks that existing slot before searching. Existing
bound-name behavior is unchanged: a genuinely shadowed file-scope publication
updates the oldest record, while a bound name without a shadow still scans and
updates the slot. No allocation, cache, new arena, SIMD path or IR is introduced.

The private test seam returns the production loop cursor rather than recording
a second global counter. Geometric tests include 0 and 1, fresh publication,
shadowed names behind unrelated records, nested reverse unwind, a bound name
without a live shadow, invalid symbols and unchanged arena position. Real-source
checks retain redeclaration diagnostics and source lines. A driver fixture in
the existing allocator-mode suite checks block/function boundaries and nested
local/function shadowing. Existing type-parser rollback tests stay enabled.
