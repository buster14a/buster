The x86 and AArch64 selectors now derive promotable-local eligibility from the
minimal selection prepass's contiguous value-definition table while
initializing their existing per-value arrays. This removes one complete
block-linked IR walk without adding a stream or assuming definition order;
target-specific scalar and x86 vector rules are unchanged. Seven interleaved
instruction rounds with byte-identical output reduce the median from
14,823,873,551 to 14,819,776,616, **-4,096,935 (-0.0276%)**.

Minimal selection prepass ownership validation now counts each instruction as
the linked block walk first claims it and compares the total with the flat
instruction count. The existing visited bytes still reject duplicate IDs at
the same point, while the count replaces a second complete visited-array scan.
The isolated median is 14,819,417,800 -> 14,812,908,906,
**-6,508,894 (-0.0439%)**, with identical output.

The scalar exact writer no longer clears its 16-byte transactional buffer.
Every successful byte is assigned in order by the prefix/opcode/ModRM/
trailing/immediate push operations, and every length or range failure returns
before the buffer is read or copied. This saves 14,812,099,340 ->
14,805,638,336, **-6,461,004 (-0.0436%)** in seven rounds without weakening
the metadata byte authority or failure atomicity.

DWARF scope emission now allocates one `scope_count + 1` iterative traversal
stack and reuses it for every function instead of advancing the arena by a
full-model stack for each root. The dead `entered` frame field is removed.
The emitted debug sections and objects remain byte-identical. Retired work
falls 14,824,752,296 -> 14,823,740,624, **-1,011,672 (-0.0068%)**; the more
important nine-round cycle medians fall 5,388,307,409 -> 5,373,541,599
(**-0.274%**) because the writer stops touching a fresh arena page for each
function.
