## Decision

Record a **neutral, no-change disposition for #988**. `dwarf_build_model`
does call the complete `dwarf_build_legacy` and discards its STR, ABBREV and
INFO payloads and their relocations. On the production route this work is too
small to measure as a compiler-throughput effect. It does not justify
extracting a shared line-program writer.

- **Census (measured, instrumented probe).** On the debug-enabled
  frozen self-host compile, the discarded construction costs at most
  614.4 µs of a 1,531.3 ms compile (**≤ 0.040 %**). It requests
  1,041,974 bytes and touches about 949,396 bytes, against a 2.0 GiB
  peak RSS. The largest share on any input was ≤ 0.21 %, on a synthetic
  32,768-function file.
- **Same-binary paired A/B (measured, diagnostic).** A switch in the same
  probe binary skipped only that work and kept validation, fallback
  preparation and the LINE program. Every output stayed byte-identical.
  The self-host median paired saving was 1.73 ms, but its 95 % interval
  [−0.96, +4.35] ms contains zero and sits inside the same-binary A/A
  interval [−3.31, +2.75] ms.
- **Transfer.** Inside the probe, the legacy phase saved 0.552 ms while
  the model writer that follows became 0.370 ms slower. About two-thirds
  of the saving therefore reappears in the next phase on this route.
- **Counters.** Retired user instructions fell by 2.81 M (0.013 %), which
  is outside the A/A instruction spread. User cycles fell by 0.069 %,
  which is not: A/A differs by 0.117 %.

Fewer temporary bytes and fewer instructions of this size are not a
throughput verdict. No production source changes.

## What the legacy call builds only to be discarded

These payloads are built and then discarded:

- STR with the string interner;
- the 35-byte ABBREV;
- one compile unit plus one subprogram per function in INFO;
- `2F+7` relocation slots (F = function count), of which all but the LINE
  entry are discarded.

The legacy capacities cannot overflow:

- STR is sized exactly;
- ABBREV uses 35 of 64 bytes;
- INFO needs ≤ 31 bytes per function out of 40 reserved, plus 47 header
  and terminator bytes out of 64;
- the relocation count is exact.

`arena_allocate` fails the process rather than returning null. Removing
the discarded buffers therefore removes no recoverable capacity path.

The call also supplies checks that the model writer does not repeat.
**A future change must keep them explicitly:**

- **Supplied-function checks.** For each supplied or model-derived
  function: `file < file_count` and the code range lies within
  `code_size`.
- **Line-entry checks.** For each line entry: `file < file_count`,
  `code_offset <= code_size`, and non-decreasing offsets. These belong
  with the line program anyway.
- **Null-pointer strings.** Interning rejects a non-empty string with a
  null pointer. That covers `input.producer` (the model writer never
  emits it), every supplied function name (the model interns `model->functions`
  names instead), and `comp_dir` and `file_paths[0]` (the model also
  interns these). Line-header emission covers every file path.
- **32-bit gates.** The legacy STR offset (dedup-dependent), INFO length
  and LINE length must each be ≤ `UINT32_MAX`. Only the LINE gate
  concerns retained output.

The line-only probe below deliberately **drops** the string checks and the
STR and INFO gates. It measures cost only; it is not a correct candidate.

## Method

on, SMT on) through a direct SSH session. The environment was:

  Python 3.14.7, perf 7.2.4.

  This is **not** the server-authoritative lease; another agent's #906

- Children were pinned with `taskset -c 2`.
- One-minute load averages at the run boundaries were 0.49–1.13.
- Runs, all 2026-09-23 UTC: census from 14:43:37; paired A/B 14:53:40 to
  14:57:23; A/A and probe − base 14:58:40 to 15:04:02.

Three checkouts of the frozen main were used, each built with `flock

**Probes.** Both probes are disposable reproduction evidence and must never
be merged into production source. They use `timestamp_take`, `getrusage` minor faults and `arena->position` to
split `dwarf_build_model` into phases:

- preparation;
- the legacy call, subdivided into validation, allocation, ABBREV/INFO/STR
  and relocations, and LINE;
- the model writer.

`census.patch` prints one `DWARF_CENSUS` line per call.
`census-line-only.patch` is the same probe plus a
`BUSTER_DWARF_CENSUS_LINE_ONLY` switch, read once per call outside the
timed spans. When set, the legacy call keeps its validation, the LINE
buffer and the LINE relocation, but skips the STR/ABBREV/INFO buffers,
the string table and the non-LINE relocations.

**Inputs.** The self-host case is the frozen base tree itself, clean
(`git status --porcelain` is empty). Its `build/generated` holds one file;

What the paired runs show:

- **Outputs.** All A, B and base objects hashed identically, including the
  52,458,408-byte self-host object
  `c7ef9d3bfb160d42cbeb9bf44199e118d6a7380c29523038bb7390421fddea9a`.
- **Cycle spread.** Within-variant `cycles:u` ranges on self-host were
  28–114 M, far larger than any A−B difference.
- **Instructions.** On self-host, within-variant instruction ranges were
  ≤ 1.62 M and the A/A difference was 0.20 M. The 2.81 M drop is therefore
  real, but it is not visible in cycles or wall time.
- **Line-heavy wall shift.** This input removes only 1,284 requested
  bytes, so its 1.5 ms shift is noise. The noise floor is the same size
  as the self-host point estimate.
- **Phase timers.** Inside the probe, B's median self-host legacy phase was
  551,668 ns shorter, its LINE sub-phase 71,890 ns longer, and the model
  phase that follows 369,848 ns longer. The net inside DWARF construction
  is about 0.18 ms (0.012 %). One possible cause is that the discarded
  interning warms the function names and input arrays the model re-reads;
  that has not been verified. On many 32,768 the model phase was instead
  257,842 ns faster.

## Scope and unrun gates

- **Not admitted evidence.** This is diagnostic evidence from an
  unadmitted host session and from probe binaries.
  `BENCH_SERVICE_DISPATCH_ENABLED` is absent and
  `9700x-service-dispatch.yml` has never run. Its only admitted recipe,
  `validate-buster-v1`, is a one-pair smoke test, not an A/A or A/B
  verdict. The admitted matched-build A/A and A/B that #988 requires for
  an implementation were **not run**; no implementation candidate exists.
- **Candidate gates not run.** All of the following are **not run**,
  because there is no candidate:
  - `.debug_line` and relocation-order identity;
  - independent `llvm-dwarfdump --verify` of linked single- and multi-TU
    output;
  - the #201 range/location regressions;
  - new registered tests;
  - Debug/Release, sanitizer and mode-matrix runs;
  - the self-host fixed point on a candidate.

  The same-binary probe's byte identity is a probe property. It does not
  show that a correct candidate would be byte-identical.
- **Reopen criterion.** Reopen only when a measured debug-enabled route
  resolves the legacy non-LINE construction above its A/A noise floor.
  Two ways that could happen: upstream phases shrink the self-host compile
  far enough that about 0.6 ms becomes resolvable, or some input has a
  much higher ratio of functions to other work. A future change must then
  keep the checks listed above and include the downstream transfer seen
  here.

## Out-of-scope observations

These are not changed and not claimed:

- **CU producer string.** The model writer emits `line_input.file_paths[0]`
  as the compile unit's `DW_AT_producer`, where the legacy writer uses
  `input.producer`. `llvm-dwarfdump --debug-info` on the tiny object shows
  `DW_AT_producer ("/home/david/bench/issue988/inputs/tiny.c")`.
- **LINE over-reservation.** The LINE buffer reserves 32 bytes per input
  row. On self-host it requests 19.7 MB and uses 2.7 MB. This is the
  retained writer's capacity policy, not discarded work; its
  requested-versus-touched cost was not measured.
- **Superlinear `-g` cost.** `-g` overhead grows faster than the function
  count: 6.8 ms at 4,096 functions and 253 ms at 32,768, while
  `dwarf_build_model` is only 5.2 ms of the latter. This audit does not
  attribute the rest. It is left to #987's owner, not bundled here.
