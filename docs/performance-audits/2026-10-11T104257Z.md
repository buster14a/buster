## Workload

Every arm compiles the same input, the base revision's unity self-host source,
from the base checkout:

```sh
ide cc -Isrc -Ibuild/v3t/generated -DBUSTER_UNITY_BUILD=1 -DBUSTER_INCLUDE_TESTS=0 \
  -target x86_64-unknown-linux -march=znver5 -g0 -fsyntax-only \
  [-fc-ast-pilot] src/buster/apps/ide/ide.c
```

4,180,888 tokens reach the parser, and the tree has 2,776,566 nodes. Under the
pilot the candidate follows the plan of all 6,656 function bodies
(`C_AST_STATEMENTS bodies=6656 segments=70925 segment_tokens=1035077
uses=272519 bails=0 declaration_hints=36241 loop_hints=4872 declines=10317
declarator_hints=36366 initializer_hints=35418 auto_skips=36241
declarator_declines=0 fallbacks=0`). There are four arms:
- A: base, default flags;
- B: base with `-fc-ast-pilot` (the statement plan without declarator hints);
- C: candidate with `-fc-ast-pilot`;
- D: candidate, default flags.

C − B is the hints' own effect, and D − A is their cost to the default path.
Callgrind ran with `--cache-sim=no --branch-sim=no`.

## Validation and limits

- Callgrind counts instructions, not time, on `-march=x86-64-v3` builds whose
  AVX-512 kernels are compiled out.
- One input, one host, single process, no pinning and no `perf` counters.
  Wall time was not measured.
- No PR benchmark request is made for this slice, and the 9700X comparison
  cannot time the hook. Zen 5 validation stays **incomplete** (#2761).
- After the runs, the Clang analyzer reported a `core.NullDereference` path
  in `c_parse_plan_append`: handing the whole plan to
  `c_parse_plan_declarators` let it assume the entries pointer could change.
  The hint builder now takes the declarator array and a local count instead.
  That change only moves data and was not re-measured.
- Correctness of the measured candidate is in the pull request's validation
  record: `c_ast_tests` and `compiler_driver_tests` in Release (unity) and
  Debug (split TU), `test_self_host --config Release`, the Clang analyzer on
  the touched C files, and a mutation check (dropping the tag-name filter on
  the hinted path alone fails the binding differential on four fixtures).
