## Hypotheses before acceptance measurement

H1: sparse publication and empty/incompatible probes make contiguous byte flags
save initialization and avoid payload work. H2: publication and successful/mixed
probes already touch enough row lines that a second stream, additional mode
gates, and allocation overhead erase the savings. H3: a local-end narrow AoS
preserves one stream and wins without shrinking scope/type IDs. The census
distinguishes the mechanisms, but cache residency, generated instructions,
arena high-water and whole-compiler attribution distinguish the time/RSS outcome.

## Concrete competing representations

Let T be body tokens, P = ceil(T/64). All scope/type IDs remain global u32.

| Layout | Concrete physical representation | Live table bytes | Initialization |
|---|---|---:|---|
| Current | `{u32 end,scope,type,flags}[T]` | 16T | Contiguous zero of 16T. |
| Flags-first replay control | `{u32 flags,end,scope,type}[T]` | 16T | Same full zero; field order and predicate order change. |
| Hot/cold candidate | `u8 flags[T]` + `{u32 end,scope,type}[T]` | 13T | Zero T flag bytes; leave unpublished payload alone. |
| Full SoA | `u8 flags[T]` + three `u32[T]` columns | 13T | Same flags zero. |
| Blocked 64 | `{u8 flags[64]; payload[64]}[P]` | 832P | Clear each complete 64-byte flags block. |
| Byte-flag compact AoS | `{u32 end,scope,type;u8 flags}[T]` | 16T | Strided flag-only clearing still touches nearly every row line. |
| Local-end narrow AoS | `{u8 flags,pad;u16 end_delta;u32 scope,type}[T]` | 12T for T<=65535; otherwise 16T | Strided flag zero; full 12T zero is a distinct alternative. |

End delta is end minus the slot's absolute starting token. An entire body uses
the wide control above 65535 tokens. The test includes 65535/65536 boundaries
and high global IDs. Narrowing scope/type from their initial count is unsafe:
type IDs can grow during validation, and the lookup has no promise that scope
IDs fit a local descendant interval. A checked spill map could solve storage,
but would add another representation and dependent access without a measured
prize. No truncation is admitted.

Hot/cold changes direct construction, not post-construction conversion. It adds
one machine pointer and one arena allocation per body, assigns payload before
the flag, and tears both pointers down together. No new scan, serialization,
append copying, or parallel merge is required. Every layout keeps one fixed slot
per token and preserves overwrite behavior.

## Explicit cost model

For each function j, T_j tokens; let Q be eligible probes and W publications.
For the current predicate let A be probes with matching end, B those also
matching scope, and C those also matching modes/checking strength. Logical load
bytes are `4(Q+A+B+C)`. For flags-first layouts let F be flag-compatible probes,
G those also matching end, and H those also matching scope. AoS-control loads
are `4(Q+F+G+H)`; split/SoA/blocked loads are `Q+4(F+G+H)`; narrow loads are
`Q+2F+4G+4H`, plus reconstruction arithmetic and body-wide fallback selection.
These sums count each flags load once despite two uses in the predicate.

Current initialization is `16 sum(T_j)` versus `sum(T_j)` for hot/cold; publication
stores are 16W versus 13W logical bytes. Table peak is `16 max(T_j)` versus
`13 max(T_j)`, before allocation alignment and other scratch. Logical post-body
retention is zero for both. Small alignment gaps and the extra machine pointer
are included in the migration discussion, rather than treating sizeof as RSS.

Every representation has one O(T) initialization operation and O(Q+W) random
operations. Split payload addressing uses the same direct slot and no dependent
index map. A flag-first predicate adds a control gate; the CPU may speculate
loads and overlap addresses, so predicate-stage counts are not measured latency.
Sparse compact payload would introduce an additional dependent slot-to-payload
load and growth/repacking. It is excluded from the implementation packet.

The C replay counts logical fields, short-circuit stages, per-event distinct
conceptual 64-byte lines, initialized lines and storage. Its streams are modeled
as separately 64-byte aligned. Actual arena allocations use native alignment;
adjacent streams can share a line, especially in tiny functions. Summed touches
are not cache misses, unique function lines, RFOs or memory-level byte traffic.
The offline census additionally records unique payload lines per body. Assembly
inspection is still needed because aggregate writes and speculative loads can
differ from logical field accesses. Replay poison stores are excluded from its
model and never represent a timing candidate.

## Why alternatives are not the initial migration

Full SoA has no field-only scan consumer: successful readers need end, scope and
type, and the publisher writes all three together. It preserves the same 13T
storage but separates mixed hit/write payload streams. Blocking adds tail slots
and addressing without an existing batch consumer. A one-token body costs 832
bytes in blocked64 versus 16 in current; a 65-token body costs 1664 versus 1040.
There is no SIMD kernel to amortize this padding.

Byte flags in ordinary AoS leave alignment padding and a 16-byte sizeof. Its
strided initialization saves logical stores but still visits the row lines;
that is not the contiguous-clearing benefit of hot/cold. Narrow AoS offers 25%
logical table reduction and usually fewer hit streams, but moves cost to end
arithmetic, shape dispatch, overflow handling and strided flag clearing. It is
a legitimate competitor for future measurement, not a current winner.

For tiny bodies the existing full memset can compile to very few stores, its
entire memo may be hot, and exact-end-first rejection is cheap. A byte plane adds
allocation/pointer and mode-mask work. For dense repeated hits the split moves
work from initialization/cold misses into hit loads and publications. These
counterexamples prevent a blanket 'SoA wins' conclusion.

The old canonical-row experiment in `2026-08-09b.md` already demonstrated the
danger: pooled offsets added 4.0-4.4% stage-1 instructions; pointer pooling added
3.0%; a pointer hot/cold split added 2.1% despite 5% fewer L1D misses. Its cycle
change was within noise. Those are historical Zen 4 results on a then-112-byte
instruction row, not current measurements. The current 64-byte canonical row
is untouched. `2026-08-22T122232Z.md` also rejects token narrowing that removes
symbol/offset facts required by real random consumers; CToken is already 12 bytes.

## Migration boundary and smallest implementation packet

Change only `CParseExpressionQuery` and `CTypeParseMachine` in c_internal.h plus
their two readers, one publisher and body construction/teardown in c_parse.c.
Gate flags before any abstract payload read; check the complete flag mask fits
u8; assert 12-byte payload; publish flags last; clear the sidecar pointer before
scratch rewind. Keep direct indexing and every eligibility/publication condition.
The experimental patch generator applies exactly those six guarded replacements.

A normal production packet would remove diagnostic poisoning, add direct tests
for dirty scratch, flags dominance/mismatch, changed range/scope and type bounds,
retain frozen syntax/object diagnostic-equivalence expectations and rollback
neighbors, and update semantic-validation guidance. It must preserve self-host
fixed point, sanitizers, both frontend forms, all affected toolchains/platforms
and one-lane/persistent-lane paths. Do not extend the table into lowering or add
an accessor callback, permanent IR, generation map or new semantic certificate.

Then compare unchanged current, flags-first AoS and hot/cold on immutable trusted
Clang builds through the existing matched-build dedicated-9700X harness. Include
frozen unity, ordinary project inputs, tiny files, many small functions, mixed
queries and large bodies; measure complete artifact time and peak RSS, with
separate work counters and build-root/A-A controls. A Pareto acceptance requires
no credible regression in either metric and a credible improvement in at least
one, plus the issue's Zen 4 non-regression obligation. Reject or retain current
on neutral/regressive complete results; a smaller table or replay-byte total is
insufficient. No new CI/admission threshold is proposed.
