## Scope and revision identity

This is the correctness/storage tradeoff for [#298](https://github.com/buster14a/buster/issues/298),
implemented in [PR #462](https://github.com/buster14a/buster/pull/462).
Per-value and per-region weighted traffic and heap keys were u32, while global
placement traffic was u64. A sum of 1,048,576 contributions of weight 4096
became zero locally; the original regional sentinel also excluded an exact
UINT32_MAX initial cost. Widening these costs to u64 and representing initial
regional enumeration through its index preserves exact ranking. Raw edit-count,
marginal-candidate, first-4096 admission and heap tie policies are unchanged.
Putting weight first limits each heap interval from 20 to 24 bytes.

Base is `d00ba87da23737a945a899f7304ac00b40a1ee04`. Local implementation is
`3a48f9b31aca815d19203c9552e0779747f623c3`; API-published implementation is
`938ae95e01640af1e59bed63a68518ac66d0250e`. Both implementation commits have tree
`32e30487d1de8abc5873e37749c664d8bfdd362e`. This later audit changes documentation
and evidence only. The two ordinary Clang 18.1.3 Release compilers use identical
configuration: unity, tests ON, CI OFF, allocation instrumentation OFF,
`-O3 -DNDEBUG`, debug information and frame pointers ON, libc ON, sanitizers and
fuzzing OFF. Binary hashes and diagnostic-build qualification are recorded in
[build provenance](evidence/2026-09-12T052805Z/validation/build-provenance.json).

## Reproduction and evidence

The build setup used the repository's documented hosted Clang bootstrap
qualification because distribution TCC could not build current build.c:

```sh
clang -Isrc -Wall -Werror -Wno-unused-function -Wno-unused-variable -g build.c -o build/build
build/build generate --cc clang --ci --linker DEFAULT -- -DBUSTER_BENCH_ALLOCATIONS=ON
# generate deletes build/build; repeat the bootstrap command before build.
build/build build --config Debug -t ide -- -j2
BUSTER_TEST_JOBS=2 build/Debug/ide test --verbose=0 --ci=1
build/build generate --build-directory build-release --cc clang --no-ci --no-fuzz --linker DEFAULT -- -DBUSTER_BENCH_ALLOCATIONS=OFF
build/build build --build-directory build-release --config Release -t ide -- -j2
BUSTER_TEST_JOBS=2 build-release/Release/ide test --verbose=0 --ci=1
build/build generate --build-directory build-sanitize --cc clang --no-ci --no-fuzz --sanitize --linker DEFAULT -- -DBUSTER_BENCH_ALLOCATIONS=ON
build/build build --build-directory build-sanitize --config Debug -t ide -- -j2
ASAN_OPTIONS=detect_leaks=0:halt_on_error=1 UBSAN_OPTIONS=halt_on_error=1:print_stacktrace=1 BUSTER_TEST_JOBS=2 build-sanitize/Debug/ide test --verbose=0 --ci=1
build/build bench_throughput self-test
```
