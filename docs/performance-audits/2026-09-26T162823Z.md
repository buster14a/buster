## Decision

A designated clear inside a constant initializer's occupied relocation extent
read and rewrote the whole relocation array. That is O(clears × relocations)
for three shapes: unordered designators, repeated designation of a slot, and
GNU range defaults with overrides.

Each designator-machine context now owns a `CIrInitializerRelocationIndex`.
The extent fast path is unchanged, and the index takes over only when a clear
may overlap a record.

- **Buckets.** Records are bucketed by offset / pointer size, one group per exact offset. A record overlaps `[start, end)` exactly when its offset lies in `(start − p, end)`, so a clear visits only the buckets that range spans. A bucket holds at most p groups. A clear therefore costs O(size / p + p) plus the records it removes, and its `memset` already costs O(size).
- **Tombstones.** Removed records stay in scratch until they outnumber the live ones, and then one stable pass drops them. Survivors keep main's order, which is the order the object writer emits.
- **Publication.** The context works in scratch sized at twice the caller's capacity and publishes its live records when it finishes.
- **Failure behaviour.** Appenders see the caller's capacity plus the dead count, so appends fail exactly where they did.
- **Legacy path.** The legacy folder's clears and any context whose index cannot be built keep the whole-array compaction.

The code is in `c_gen.c` only, plus a test seam in `c_gen_internal.h`. No retirement-bound source is touched.

- **Local runs.** The full `ide test --ci=1` suite passes, except the two host-only `wide_vector_boundaries` assertions (#1292), which fail on main too. The self-host fixed point holds at 46,693,704 bytes. Clang's analyzer is clean in the production and tests configurations.

## Limits and findings

- The index's scratch is about 2.6 × the caller's relocation array while a context needs it. It is rewound with the initializer's temporal arena. Ordered and descending tables never allocate it.
- **A positional element overwriting a designated slot** (`{[1] = &a, [0] = &b, &c}`) leaves two relocations at one offset on main. The canonical validator rejects that module, but on the input-certified C path the failure only turns FAST off. COFF and Mach-O output then keeps `&a`, which is a miscompile outside this change. The index preserves main's records exactly.
