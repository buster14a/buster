## Workload

Every arm compiles the same input, the base revision's unity self-host source,
from a checkout of the base:

```sh
ide cc -Isrc -Ibuild/generated -DBUSTER_UNITY_BUILD=1 -DBUSTER_INCLUDE_TESTS=0 \
  -target x86_64-unknown-linux -march=znver5 -g0 -fsyntax-only \
  [-fc-ast-pilot] src/buster/apps/ide/ide.c
```

Four arms:
- A: base, default flags;
- B: base with `-fc-ast-pilot`;
- C: candidate with `-fc-ast-pilot`;
- D: candidate, default flags.

D − A is also measured on `-c` (`-g0`, the same input with `-c -o`). Callgrind
ran with `--cache-sim=no --branch-sim=no`.

## Census

The census build was a throwaway tests-off build of the base, not committed.
For every query the typer declined, it printed:
- the deepest declined node on the operand path;
- the member rule's reason, when that node is a member;
- the node's tokens.

The machine run that followed went through a per-class `noinline` wrapper,
so Callgrind charges each class its inclusive machine Ir. The run also
recorded rows appended, diagnostics, constraint and validity. It counted
24,759 declines, the typer's own `-v` count. An earlier version of the
census build broke the memo-hit branch, so memo hits ran the machine too; it
counted 38,744. Its numbers were discarded.

The checked casts declined in the operand itself: 254 on this base (236 on
the base that audit `2026-10-10T193402Z` measured).

| member of a const aggregate, the operand itself | 82 | 1 each | 0.48 M |
| member of a const aggregate, deeper | 59 | 1 to 3 | 0.46 M |

The shapes that append nothing total 56 queries and at most 0.71 M machine
Ir. That is below the declared 1 M gate, so no candidate was built for them.

Every other decline had the member rule's qualified aggregate as its
deepest declined node in 8,818 queries (44.9 M machine Ir). In 3,650 of them,
at 7.79 M, the query's node is the member itself:
- 1,965 unchecked and 1,685 checked;

Of the other 5,168 (37.1 M), the query is larger than the member, and
574 appended nothing. That is unverified, but probably the member's range was
already in the memo. The remaining declines were not examined further:
- 11,312 with another deepest node (58.6 M);
- 3,254 `&` (5.1 M);
- 753 calls (3.4 M);
- 345 string literals (2.3 M);
- 23 members over a base kind the rule does not take (0.1 M).

## Reading

- The declared census gate fails for the checked casts this item set out to
  widen. The members among them append rows, and so do the string runs and
  the `&`. The shapes that append nothing are worth 0.71 M at most.
- The member replay saves about 7.8 M of machine work over 3,650 queries,
  about 2,100 Ir each. Code-generation changes in the query function, which
  every query runs, take back most of that. The versions above moved the
  pilot by −1 M to +21 M, and the default path by −0.03 M to +15 M, without
  changing any work. The shipped version clears the 1 M gate by 11,652 Ir.
  A later unrelated change to the query function could undo that.
- The same lesson as #3384's: replacing cheap machine queries pays only when
  the new code stays off the inlined answer path. Here that required an
  out-of-line decline that returns its answer by value.
- Hosted wall time was not measured. Zen 5 validation (#2761) stays
  incomplete, and the hook stays opt-in.
