## Coverage contract

Base `79dc4b8cba3258d1b6d3db3a4e0ab31cdc88ae0c` is PR #356's merged,
fully validated tree. Full Linux x86-64 compiler builds already had zero
fallback. The focused Windows fixture had seven: six variadic definitions
rejected by the signature gate and one caller rejected at `CALL`.

Windows and UEFI variadic functions now home RCX/RDX/R8/R9 before argument
capture can reuse them. Their caller-owned homes are contiguous with stack
arguments. Both homing and `LEA_INCOMING` include the callee-save displacement
recorded by placement, so a saved register before RBP does not shift the
cursor incorrectly. A hidden aggregate-result pointer occupies the first
positional slot. The QUALITY hidden-result fixture actually saves R15 before
setting RBP and passes the independent caller test.

The pointer-sized argument list starts after named slots, advances eight bytes
per anonymous argument, and reads indirect aggregates through the canonical
Win64 ABI classification. `va_copy` copies eight bytes and `va_end` writes
nothing. Scalar floating arguments are duplicated into their positional GPRs
in the integer staging pass, after XMM bridge operations; Windows calls omit
the System V AL count. These rules follow the [Microsoft x64 calling
convention](https://learn.microsoft.com/en-us/cpp/build/x64-calling-convention?view=msvc-170).

The two appended opcode identities and expansion recipes preserve existing
IDs. Ordinary pointer/frame rows handle argument reads and copies. The direct
emitter is unchanged. Existing Windows indirect aggregate argument and vector
signature restrictions remain; the selected aggregate reads are bounded to
sixteen bytes, matching the direct variadic oracle. This stage does not close
#36 or remove production fallback.
