- **Short vectors and indirect arguments (signature 17 to 1, CALL 3 to
  1).** One AArch64 story: a sixteen-byte vector rides a whole V
  register at the ABI edges while the value stays slot-backed
  (VLOAD_FRAME/VSTORE_FRAME, fixed-V payload rows on the scheduler's
  float-state chain), and everything past sixteen bytes — aggregate or
  vector — travels as a pointer in the integer file, overflowing to a
  scalar stack part like any integer. The machine caller points that
  pointer at a **defensive copy**: AAPCS64 licenses the callee to
  scribble on the pointed-at memory, which the canonical caller's
  pass-the-value-slot shortcut does not survive. The callee copies in
  through the pointer at entry and the parameter is an ordinary
  slot-backed aggregate from there.
