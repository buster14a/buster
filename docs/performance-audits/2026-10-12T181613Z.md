## Mechanisms and regression coverage

1. `c_type_parse_sizeof_step` previously scanned every remaining assignment
   suffix. Its right-child hint now stops at the next root assignment when
   the parent proved no comma, retaining the complete scan after a preceding
   conditional and dropping the proof when a group/identity opens.
2. Semantic assignment validation asks for every suffix separately. Completed
   assignment tasks now publish their type to the existing scoped/mode-aware
   memo, only from a root that appended no types, mutations or diagnostics.
3. `c_parse_constraint_expression_end` previously walked each remaining suffix
   too. A guarded per-body backwards endpoint table supplies the same answer,
   clamped to each caller's bound; malformed delimiter streams retain the walk.
4. Lowering rescanned each suffix for commas and root conditionals. Assignment
   continuations now retain the parent's comma-free range; the root conditional
   scan stops at an assignment that already determines its negative answer.

The focused frontend run on the measured implementation passes 1,481,719 unit
assertions. The new tests include actual type-task/operator/endpoint/lowering
work at geometric depths through both frontend SSA forms, an exhaustive
indexed-versus-walked endpoint comparison, and executable mixed assignments
through FAST and QUALITY with strict backend verification. The final branch
expands the counted depths from 256/512/1,024 to 5,000/10,000/20,000; that
larger test population is separate from this measured binary's identity.
