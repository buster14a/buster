## Decision

Three searches ask which type row was defined at a given token, and each
scanned the parse type table from row 0:

- `c_type_parse_core_step` asks it for a declaration whose base type is an aggregate definition;
- `c_parse_bind_expression_aggregates`;
- lowering's anonymous-aggregate type names in `c_ir_type_name_prefix`.

On a first parse the row does not exist yet, so the scan misses and walks every row. For Q definitions over T other rows that is Q(2T+Q-1) visits.

The replacement is `CDefinitionIndex`, which maps each definition token to the lowest type id ever given that `definition_start`.

- **Why the lowest id is a lower bound.** `c_parse_scalar_type_core_begin` is the only writer of `definition_start`, so no live row with a start is older than the recorded id.
- **Rollback.** The header outlives rollback and recorded ids only ever decrease. A stale record is therefore still a lower bound.
- **Queries.** Each query starts its unchanged scan at the recorded id. It skips the table entirely when the start was never assigned. It starts at row 0 when the index is incomplete (arena exhausted) or absent.
- **Answers.** They are those of the full scan: the same first match, from the same predicate.

The code is in `c_parse.c`, `c.h`, `c_internal.h` and `c_gen.c`. The
diagnostic counts are tests-and-counting-build fields on the index, not
construction counters, because syntax-only runs must leave the IR
construction census untouched. No retirement-bound source is changed.

## Equivalence and validation

- **Objects.** In census run 3, all 141 input × flag groups produced byte-identical objects across every ref.
- **`c_test_definition_index`.** It drives the index through growth from 4 slots, minimum and maximum records, rollback with id reuse, and the incomplete and absent paths.
- **Real parse in the same test.** 64 typedefs and 64 definitions must take 64 searches and zero scan rows.
- **Syntax-only and semantic-only runs** still leave the IR construction counters unchanged (`compiler_driver_test_syntax_diagnostic_equivalence`, `c_test_initializer_frame_bounds`).
- **Local runs.** The full `ide test --ci=1` suite passes, except the two host-only `wide_vector_boundaries` assertions (#1292), which fail on main too. The self-host fixed point holds at 46,688,440 bytes.

## Limits

- The index holds two `u32` per recorded definition start in the parse arena, at no more than half occupancy.
- The anonymous-aggregate scan in lowering keeps its predicate and first-match rule.
