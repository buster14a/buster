## Changes and constraints

- **#201:** DWARF v4 range/location endpoints are now CU-relative offsets.
  The CU retains its relocated `DW_AT_low_pc` and size-valued `high_pc`.
  Removing endpoint relocations prevents applying the module text base twice,
  including when objects' debug sections are concatenated. Global-address
  expressions and ordinary code-address relocations are unchanged.
- **#202:** bounded `LF_FIELDLIST` segments carry `LF_INDEX` continuations.
  Segments are emitted tail-first with backward references; semantic member
  order is unchanged. Every member has its own descending `LF_PADn` bytes.
  Auxiliary references are patched at their actual emitted indices, including
  mixed function/aggregate models. PDB normalization and deduplication remap
  continuation references and every member after padding. `LF_UNION` does not
  contain the structure-only derived/vshape slots. Name bytes are included
  in capacity estimates, and an unrepresentable single record/count produces
  an explicit driver diagnostic rather than wrapping or omitting debug data.
- **#203:** after splitting `.debug$S`, the PDB writer reconstructs parent/end
  links from record nesting in the final symbol-stream coordinate system,
  including the module's four-byte signature. Procedure, block, inline and
  thunk scopes use one module-local stack. Mismatched/orphaned end records,
  truncated records and unclosed scopes are rejected.
- **#204:** one scope stack plus first-child/next-sibling arrays per CodeView
  build replaces a module-sized stack allocation per function and repeated
  full-model child searches. Reverse insertion preserves ascending scope-id
  order. The child index is O(scopes), as is its storage; traversals visit
  their actual descendants. The separate inline-site scan is not changed.

The continuation format follows LLVM's `ContinuationRecordBuilder`: an
8-byte `LF_INDEX` member and a maximum record size of `0xff00` including
its prefix. Oversized single members/argument lists are diagnosed rather
than inventing a nonstandard encoding.

## Controlled scope-allocation A/B

The checked-in regression builds 256 and 1,024 functions, each with a root,
child and grandchild. Scope ids are grouped by depth, so descendants are not
adjacent to their parents. The measured arena delta begins after allocating
the input model and includes output buffers, relocations, types and scratch.
The A/B restores only the original scope walker/allocation from `main` in
otherwise identical patched code; it does not conflate the type-stream fix
with traversal cost. Clang 17 Debug, non-unity, same process environment:

| Functions / scopes | Original walker | Indexed reusable walker |
| --- | ---: | ---: |
| 256 / 768 | 1,707,296 bytes | 144,672 bytes |
| 1,024 / 3,072 | 25,701,152 bytes | 576,288 bytes |

Four times the input takes about 15.05 times the allocation with the old
walker versus 3.98 times with the new one. At 1,024 functions this removes
25,124,864 allocated bytes, including the unchanged output allocation in
both totals. Restoring the old walker fails exactly the three allocation
bound/scaling assertions; the other 395,026 assertions still pass. No timing
or retired-instruction speedup is claimed from this experiment.

## Correctness and local gates

- Patched non-unity Debug: 395,029/395,029 assertions, 39/39 modules.
- New structural tests decode 4,096-member structures and enums through at
  least two continuation links, verify every member's order/value/type and
  padding, exercise the exact single-member boundary and its overflow, and
  merge two large PDB modules whose identical local indices name different
  builtins. Final MSF module-stream tests check two procedures, four nested
  blocks and two inline scopes, with interleaved C13 line subsections.
- DWARF tests apply actual address relocations at two distinct nonzero module
  bases, then interpret CU-relative function/scope/location ranges.

  executable/PDB and a 4,096-field COFF object. The pristine compiler silently
  emits zero-sized `.debug$S` and `.debug$T` for the large aggregate; the fix
