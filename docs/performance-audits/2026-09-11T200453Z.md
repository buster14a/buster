## Remote capture tool

`tools/remote_superluminal_capture.py` packages the successful manual method
without putting build policy into a shell script. It requires a clean remote
checkout, records the commit/tree before preparation, runs the existing
build-driver Release target unless explicitly skipped, verifies source identity
again, rejects non-family-26/non-AVX-512 hosts by default, deploys a command-line
redistributable only when absent, records/resolves/exports the canonical stage-1
workload and downloads the `.slp`, raw `.linux`, metrics, provenance and hashes.
Remote root output ownership is restored even after a failed capture.

The tool is a diagnostic convenience and explicitly does not replace the
qualified paired harness. Direct SSH operation cannot establish physical
isolation or scheduler-enforced host ownership. Do not run it concurrently with
throughput experiments; #437 owns a durable queue/service instead of extending
this helper into a remote execution authority.
