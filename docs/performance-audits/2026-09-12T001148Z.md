## Decisions

- The compact canonical FAST pipeline from #40 is enabled by default.  The
  whole pipeline and each of folding, address normalization, DCE and parameter
  cleanup remain independently switchable.  On the final rebased source, the
  repository guard found no confirmed regression and no inconclusive case in
  the A/A control, all-on versus all-off comparison, or any leave-one-pass-out
  comparison.  This is acceptance under the repository's declared practical
  guard, not a claim that every individual median improved.
- The final missing #41 acceptance is satisfied.  The merged scheduler change
  was compared directly with its parent in FAST mode on the same host.  All six
  generated workloads and both frozen self-host stages had no confirmed or
  inconclusive wall/RSS regression, with exact output identity required.
- Keep all four canonical passes in the default.  Removing DCE made the
  backend-pressure medians worse; folding was mixed but bounded; address
  normalization and parameter cleanup were near neutral.  None justified a
  measured-negative default or a special mode gate.

## Protocol

All guarded runs used the repository's native `throughput` harness with the
`ci` corpus, two fixed opposite-order rounds, 30 pairs per round, two warmups,
CPU 2, and cooperative lock `/home/david/bench/host.lock`.  The machine label
was `zen5-9700x-b404038-k6.18.50`: an AMD Ryzen 7 9700X with microcode
`0xb404038`, Linux 6.18.50-2-lts and 64 GiB RAM.  CPU 2's SMT sibling is CPU 10;
SMT remained enabled.  The harness records physical isolation and sibling
idleness as unverified, so this audit does not upgrade those observations into
hardware attestation.

The guard requires both a 15% relative and 2 ms absolute wall increase, or both
a 20% relative and 16 MiB absolute peak-RSS increase.  The applicable
one-sided exact sign test must pass in both rounds, with a family-wise 1%
nominal alpha and Bonferroni correction.  All samples are retained.  A/A and
#41 also required cross-variant output identity; #40 on/off and ablations
permit intentional cross-variant optimization differences while still
requiring deterministic output within each variant.

The final #40 series contains 17,760 timed process observations:
