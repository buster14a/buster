## Scope and ordering contract

[GitHub #104](https://github.com/buster14a/buster/issues/104) requires source-map
finalization whose cost does not depend on region displacement. Baseline:
`fd0ba8ff8175952d12bbdb367adef13effcc4865`.

`c_source_map_sort` first scans adjacent unsigned 32-bit `start` keys. An
already ordered or empty map allocates nothing and changes no rows. Otherwise,
four stable least-significant-byte radix passes alternate the existing region
array with one temporary array. Forward scatter preserves append order for
ties. All fields move together, and the fourth pass finishes in the original
array before its arena checkpoint is rewound. Origin recovery, publication,
binary-search keys, pages and C23 respelling retain their existing order.

The initial scan performs at most N-1 comparisons. Each of four passes performs
N histogram visits, 256 prefix entries and N row scatters. Thus finalization is
O(N), independently of inversion count, with no recursion or new dependency.
This bounds this finalizer, not every preprocessing operation.

The private test seam calls that production helper. Registered tests cover
empty/singleton maps, ordered/equal/reverse/permuted keys, all four byte
boundaries through UINT32_MAX, stable ties, permutation uniqueness, every
semantic payload field, surrounding canaries, scratch poisoning and repeated
finalization. Small source fixtures check exact line, column, logical file and
token spelling across `#line`, macro arguments, stringification, pasting and
builtins. The benchmark separates record-level ordering from whole-process
preprocessing of ordinary checked-in source; it does not establish end-to-end
worst-case source scaling.

The trusted Clang Release binary ran the registered opt-in benchmark, one
warmup and seven samples for each size/order. Construction, checks and poisoning

All five orderings and all 140 raw samples are in
[sort-bench.log](evidence/2026-09-12T152116Z/sort-bench.log). Cache effects and
scheduling noise make wall time nonuniform per row; the bounded traversal above
establishes complexity. No timing threshold is added to tests.

The old finalizer used no temporary arena buffer. The replacement uses exactly
`N * sizeof(IrSourceRegion)` bytes plus possible alignment for unordered maps:
80N bytes on this host, measured with fresh arenas so old pool high-water marks
cannot contaminate the result. All ordered/equal cases measured zero. The
temporary allocation is logically rewound on every sorting call, and the
histogram occupies another 1,024 bytes on the stack. Logical rewind does not
decommit physical pages. Published row sizes/counts and retained storage are
unchanged; peak resident memory must be assessed separately.
