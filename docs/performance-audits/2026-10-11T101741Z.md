## Method

Function and call-site Ir come from the B profile. Inlined helpers are
charged to the function they are inlined into, so self cost is grouped by
source line and by the file that inlined the code.

The census patch (below; not committed) makes three changes:
- Before each core's two prepasses it classifies the core's range in a
  noinline `census_classify`. It records whether the range holds a `?`,
  `&&`, `||` or assignment-operator token, and whether it holds a `(`.
- It routes each prepass through one of two noinline wrappers by that
  class, so Callgrind's call edges split the prepass's inclusive Ir. It
  counts what each class found: groups prepared and calls hoisted.
- It counts the range tokens and, per token, how many cores' ranges covered
  it.

CEN2 adds a split of `c_ir_unary_expression_end` by whether its
`[start, end)` holds a `++`/`--` token (an O(1) prefix count), and aborts if
a range without one ever returns a postfix end. It never aborted.

## Decisions

1. **About 296 M of the evaluator's structure cost needs no tree.** That is
   the empty prepasses (140.6 M + 54.0 M) and the empty postfix probes
   (about 101.8 M from the evaluator). Exact per-body prefix counts answer
   them on the default path. Filed as
   [#3445](https://github.com/buster14a/buster/issues/3445). The tree's
   slices are budgeted net of it, so the tree is not credited with this
   saving.
2. **The first tree slice (5a) is the hoist set.** It replaces both
   prepasses for the cores that do find something, a ceiling of about
   280 M. Its emission order is the token path's: hoisted groups, then
   hoisted calls in the postorder of their nesting, then the core's
   operators in postorder. Its budgets are declared in `ast.md` § Measurement
   plan, before any candidate run.
3. **No tree slice was built here.** Slice 5a consumes the lowering
   hand-off and the range-to-node index of slices 1–2. Those are claimed on
   #3102 by other sessions and have not landed, and building them here
   would duplicate that work.
4. **Row 8 retires last.** Lowering asks 68.6 M worth of delimiter
   questions, spread over four slices. The stream index they read is built
   for the parser as well. The plan is node walks that skip intervals by
   extent, plus checked outward ends where a token range is still needed.
