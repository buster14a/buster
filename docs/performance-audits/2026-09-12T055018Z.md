## Root-cause and correctness controls

Actual baseline-helper instrumentation confirms N(N-1)/2 comparisons for N
unique insertions: 523,776 at N=1024. The matched insertion/gap/repeated-key/
reverse-lookup sequence performs 2N²+N old comparisons (2,098,176 at N=1024).
The registered production probe records 4,087 map reads at N=1024, within its
4N bound. This is deterministic work evidence, not a timing threshold.
The counter exists only when both INCLUDE_TESTS and BENCH_ALLOCATIONS are ON;
ordinary compilers have neither counter storage nor increments.

Tests cover empty and filtered maps, populated map/vector growth, duplicate-key
metadata preservation, missing keys, overflow rejection, globals, functions and
synthetic strings. The canonical IR string test is necessary because ordinary
C strings do not use the synthetic-symbol path. Its 65 functions distinguish
IR keys, record indices and final ELF indices, with mixed bindings and 130
repeated string references. Both base and patch pass 738 assertions and emit
the same 14,024-byte object (SHA-256
`9ef377bc350545d8ef955a36fdc81ad9320965f6363aa269797c6db5a3b22c9c`).
The separate global oracle binds ABS64 relocations to each owning pointer
initializer's exact section/offset and LDDW targets to the owning function;
the unchanged baseline passes all 23 assertions.

Sanitizers exposed an existing `memset(NULL, 0, 0)` padding call in this path.
Zero-length buffer padding now returns successfully before touching the buffer;
nonzero behavior is unchanged. The actual baseline UBSan failure is retained.
Independent source/oracle reviews corrected incremental-growth and source-owner
coverage gaps before the final code checkpoint. No material finding remains.
