## Decision

Under `-g`, `debug_model_build` found the IR function behind each debug seed
by scanning the module's functions from the start until the symbol matched.
With F seeds in source order that is (F+1)(F+2)/2 row visits.

The replacement builds, once per model, a scratch `u32` array indexed by
program symbol. It is filled backwards, so the first function carrying a
symbol wins, as the scan's first match did. Each seed is then a single load.
A seed whose symbol lies outside the program's table keeps the linear scan;
codegen never emits one. The array is released when the seed loop ends.

The code is in `src/buster/lib/compiler/debug/debug.c`. The new counters are
`debug_function_index_rows` and `debug_function_seed_scan_rows`.

## Equivalence and validation

- **Objects.** In census run 3, all 141 input × flag groups produced byte-identical objects across every ref, including this one. The `-g` inputs are the debug families and the `-g` self-host unit. `sqlite3.c` (#1414) and Lua `ltablib.c` fail identically everywhere.
- **`debug_test_function_seed_index`.** 513 seeds against a permuted module must resolve to the same functions as the scan. The seeds include duplicate symbols (the first function wins), symbols without functions, and a seed outside the symbol table (the fallback scan).
- **Local runs.** The full `ide test --ci=1` suite passes on a tests + counting build, except the two host-only `wide_vector_boundaries` assertions (#1292), which fail on main too. The self-host fixed point holds at 46,675,520 bytes.

## Limits

- The index costs 4 bytes per program symbol of scratch per debug model, and it is rewound when the seed loop ends.
- This PR adds two counters to `src/buster/lib/compiler/ir/ir_construction.h`, a retirement-bound source, so ordinary merge waits on the trusted integration writer.
