## Consumer-specific representation and proof boundary

The domain is eligible non-block-local owners reaching `ir_promote_global`
within one function's promotion invocation. Entry, block IDs, reachability,
ordered deduplicated predecessor lists, and terminator targets/multiplicities
are fixed. Classification and CFG validation precede the quotient; dense
compaction follows it.

Fold each owner's ordered events to `A`, `E[b]`, and `U[b]`: A retains event
reachability and load-after-reset rejection; E is forward, last STORE, or last
LOCAL/lifetime reset; U records a LOAD before any definition/reset in a block.
Two owners are equivalent exactly when these facts match in that fixed context.
This is a conservative sufficient relation, not a claim of minimality.

Only `(analysis_safe, propagated_live_in)` is shared. The forward equations are
`bad_in = entry/unreachable/predecessor-free OR predecessor bad_out` and
`bad_out = reset OR (forward AND bad_in)`. Safety is A and absence of a seeded
load with bad incoming state. On safety, backward liveness is the least fixed
point `live[b] = U[b] OR (forward[b] AND any successor live)`.
Equal inputs to these monotone equations give equal fixed points. Equal event
summaries remain equal under a common appended event, hence any common finite
suffix. Arbitrary event/CFG mutation invalidates the relation.

The quotient does not merge C variables, types, scopes, stored values, source
records or SSA identities. Original event lists, per-block STORE RHS values,
canonical type/local IDs, qualifiers/escape decisions, and provenance remain.
Parameter numbering, current capacity checks, typed incoming construction,
single-predecessor value forwarding, removal, alias resolution, compaction and
canonical validation still execute for each owner. Earlier promotion marks
removals and appends parameters without changing later event opcodes/blocks or
terminator targets before final compaction. Queue contents are scratch; later
consumers reset their bounds before use.

Counterexamples retained in the proof/model: LOAD;STORE versus STORE;LOAD;
LOCAL reset versus STORE; unreachable predecessors feeding reachable reads;
event-level rejection; equal signatures in different CFGs; and equal Boolean
answers when the first owner's parameter allocation exhausts the second
owner's capacity. The last case forbids caching final materialization success.
The mixed int/double/pointer control keeps distinct stored values and types.
Existing eligibility and barrier rules remain the authority for volatile,
atomic, escaping, unresolved-layout and unsafe-call cases.

falls back to original kernels on overflow. There is no cross-function or warm

A key cell combines two existing bytes and writes one new byte; compared byte
positions and copy bytes are logical counts, not complete hardware traffic or
CPU instructions. The saved counts in share traces are counterfactual work
copied from an exactly matched representative; observe traces supply the
original executed counts. Actual executed kernels are N minus shared calls.

Even uncapped sharing removes less than 1% of memory-form kernel block and
edge visits. Cap8 removes 0.2213% of block visits and 0.1436% of edge visits,
while constructing 22.7 million key cells. These unlike operation units must
not be subtracted as a cycle estimate. Default mode removes literally no work,
so its extra construction/lookup/copy work has no compensating kernel saving.

`PromotionQuotient` metadata (248 bytes in this hosted build). The per-call
probe, metadata initialization, environment checks, alignment/arena overhead,
and trace formatting/I/O are additional costs. Existing block/value arrays
remain. The maximum above covers traced functions and is not peak RSS or arena
committed capacity; invalid-CFG setup is not a traced population. Diagnostic
text uses a temporary B+512 buffer. The offline census's full-key sorting and
bounded workspace are measurement apparatus, not hidden production allocations.
