## Decision

The integrated #2628 candidate preserves the current validator leaf checks and
fuses the canonical ownership, value, and row traversals. On one immutable
stage-1 input, both instrumented compilers produced byte-identical output and
the same semantic validation population. Five ownership work counters fell.
This establishes the intended work reduction and hosted correctness for the
pinned source. It does not establish a compile-time speedup. Keep #2628 draft
until the dedicated Ryzen 9700X comparison is qualified.

The source also corrects a fused-loop error guard that otherwise could have
repeated a rejected row without advancing. The complete registered tests and
the diagnostic IR module passed on the corrected source.

allocation counters enabled, no sanitizers, fuzzing, or LTO, and a non-unity
build. The instrumented baseline and candidate binaries were frozen before

generated header, from the same working directory with identical arguments

checked around the two invocations.
