## Measurements

Two self-compiled Buster executables were built with the same unity command, differing in the frame-placement implementation at the base versus this change. Both compiled the same diagnostic CPython translation unit with `-O3 -fregister-allocator=fast` and the same options. The evaluator's x86-64 stack allocation in the object prologue fell from **4,096 to 1,752 bytes** (57%). The trusted Clang-built Release compiler also produced a 1,752-byte evaluator frame with the diagnostic input.

Five alternating object compiles per executable gave median wall times of **0.968 s before** and **1.355 s after**. This 40% throughput cost on this large input is material. The implementation bounds the block-occupancy colorer to 3 MiB per plane and 25 million compared words, then falls back to the prior row-range colorer. The compile-time comparison uses self-compiled drivers; it is not a trusted Release throughput benchmark.

The resulting object was linked into a CPython runtime whose other files were compiled by Clang. A C `functools.lru_cache` Fibonacci probe with a recursion limit of 10,000 **passed at depth 2,857** under the default 8 MiB stack. Both actual `TestLRUC.test_lru_recursion` and `TestLRUPy.test_lru_recursion` methods passed when the mixed build was supplied a minimal `_testcapi` module containing the pinned Linux release `Py_C_RECURSION_LIMIT=10000` constant. The CPython configuration disabled test modules, so these methods otherwise skip. Neither result is a pristine Buster-built CPython harness verdict.

## Mechanism and next work

FAST now records the CFG blocks occupied by spill homes and shareable selector frame slots, then colors branching functions by block overlap instead of a single convex row span. Frame-copy source and destination are counted separately. For slots with fully known accesses, a narrow store ends the prior value when it covers every byte any read can observe. A frame address remains shareable only if all uses, including copies, resolve to bounded scalar accesses at the correct slot offset; unproved uses keep dedicated storage.

The evaluator still needs 138 simultaneous scalar spill homes in the current CFG liveness model. The layout also uses the minimal allocation that preserves sixteen-byte alignment after an odd callee-saved push count; this removes the final 16 bytes needed for the depth-2,857 probe. The unmodified CPython compatibility harness remains blocked by the separate intrinsic and static-inline call-lowering failures, so this diagnostic result needs a future pristine run to establish full compatibility.
