## Commands

All commands run in the directory holding `sqlite3.c`.

```sh
valgrind --tool=callgrind --callgrind-out-file=cg_base.out    ide_v3_base cc -g  -c sqlite3.c -o cg_base.o
valgrind --tool=callgrind --callgrind-out-file=cg_new.out     ide_v3_new  cc -g  -c sqlite3.c -o cg_new.o
valgrind --tool=callgrind --callgrind-out-file=cg_base_g0.out ide_v3_base cc -g0 -c sqlite3.c -o cg_base_g0.o
callgrind_annotate --inclusive=yes cg_base.out   # and --inclusive=no for self
BUSTER_DEBUG_INDEX_COUNTS=1 <counters binary> cc -g -c sqlite3.c -o cnt.o 2> sqlite_counters.txt
```
