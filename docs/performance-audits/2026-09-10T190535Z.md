## Behavior and compatibility

from the existing `wait4` result, after the wall interval ends. Exact `uint64_t`
values and independent availability bits distinguish zero from unavailable.
macOS and Windows retain explicit unavailability; no platform equivalence or
Windows total-to-split conversion is claimed.

Timing and separate PMU/allocation CSVs append four diagnostic columns. Result
schema 2 rejects old bundles with an explicit version diagnostic. The generated
workload's schema remains 1, preserving byte identity. JSON reports diagnostic
medians; partially available series have null medians. These counters never
participate in either statistical gate. Existing exit semantics, sealed raw
evidence, thresholds, pairing, sample counts and output/work checks remain intact.
