## Workload

Every arm compiles the same input, the base revision's unity self-host source,
from the base checkout:

```sh
ide cc -Isrc -Ibuild/v3t/generated -DBUSTER_UNITY_BUILD=1 -DBUSTER_INCLUDE_TESTS=0 \
  -target x86_64-unknown-linux -march=znver5 -g0 -fsyntax-only \
  [-fc-ast-pilot] src/buster/apps/ide/ide.c
```

4,092,279 tokens reach the parser, and the tree has 2,710,919 nodes. Four arms:
- A: base, default flags;
- B: base with `-fc-ast-pilot`: the tree and the stage-1 typer;
- C: candidate with `-fc-ast-pilot`: the tree and the stage-2 typer;
- D: candidate, default flags.

C − B is stage 2's own effect, C − A is the end-to-end effect of turning the
pilot on, and D − A is the cost to the default path. Callgrind ran with
`--cache-sim=no --branch-sim=no`.

## Reading

- Stage 2 turns the pilot from a 2.11% instruction loss into a 2.88% gain on
  this input. The tree's build cost is unchanged.
- The machine runs it removes are the expensive ones (about 4,320 Ir each),
  where stage 1 removed the cheap ones.
- What the machine still answers in bodies is nearly all row-appending:
  - casts to primitive or pointer type names, 104 M;
  - `&`, 33 M;
  - string literals, 29 M.

  The tree cannot answer these without appending the same rows. For a cast,
  the row count depends on how many machine task levels scan the
  parenthesized type name, so the shape is declined, not imitated.
- Outside typed bodies (225 M) and misses (85 M) are the other large items.

## Validation and limits

- Callgrind counts instructions, not time, on `-march=x86-64-v3` builds whose
  AVX-512 kernels are compiled out; architecture-neutral deltas transfer.
- One input, one host, single process, no pinning and no `perf` counters.
- The 9700X pull-request comparison runs default flags only. It can compare
  arm D against A, but cannot time the hook. Zen 5 validation of the typer
  therefore stays **incomplete**.
- Correctness of the measured candidate:
  - `c_ast_tests` and `compiler_driver_tests` in Debug (split TU) and Release
    (unity), including the corpus verify gate;
  - `test_self_host --config Release` (fixed point at 39,797,744 bytes);
  - the Clang analyzer, with the CI flags, on `c_parse.c` and `c_ast_types.c`.
