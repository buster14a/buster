## Change

The base grows the tree's four node columns in fixed-size chunks in the phase
arena, then seals them: one copy of the whole tree into exact-sized arrays in
the caller's arena. The candidate writes each column in place in its own
private arena. Each arena reserves address space for 2^28 nodes and commits
65,536 nodes at a time; the published tree owns the arenas until
`c_ast_release` (the
[storage contract](../agents/frontend/ast.md#storage-and-lifetime)). A tree
larger than the reservation would move once per doubling, and
`column_copy_bytes` would count it. The self-host tree fills about 1% of the
reservation and never moves.

## Workload

Every arm compiles the same input, the base revision's unity self-host source,
from the base checkout:

```sh
ide cc -Isrc -Ibuild/v3t/generated -DBUSTER_UNITY_BUILD=1 -DBUSTER_INCLUDE_TESTS=0 \
  -target x86_64-unknown-linux -march=znver5 -g0 -fsyntax-only \
  [-fc-ast-pilot] src/buster/apps/ide/ide.c
```

4,105,792 tokens reach the parser, and the tree has 2,721,682 nodes (0.663 per
token). There are four arms:
- A: base, default flags;
- B: base with `-fc-ast-pilot`;
- C: candidate with `-fc-ast-pilot`;
- D: candidate, default flags.

C − B is this change's effect on the pilot, and D − A its cost to the default
path. Callgrind ran with `--cache-sim=no --branch-sim=no`.

## Reading

- The seal copy and the full-tree transient are gone, and the tree and the
  objects are unchanged.
- The phase arena now holds 60 KB at its peak instead of the whole tree.
- The pilot's compile loses 33 M instructions and 8 MB of peak RSS.
- The default path is unchanged.
- A 2^28-node reservation per column costs address space only. It keeps
  every tree up to `C_AST_NODE_LIMIT` supported, and no bound on nodes per
  token is assumed.

## Validation and limits

- Callgrind counts instructions, not time, on `-march=x86-64-v3` builds whose
  AVX-512 kernels are compiled out; architecture-neutral deltas transfer.
- One input, one host, single process, no pinning and no `perf` counters.
- The 9700X pull-request comparison runs default flags only. It can compare
  arm D against A, but cannot time the hook. Zen 5 validation of this change
  therefore stays **incomplete** (#2761).
- Correctness of the measured candidate:
  - `c_ast_tests` (118,269) and `compiler_driver_tests` (61,715) in Debug
    (split translation units) and Release (unity), including the corpus
    verify gate;
  - `test_self_host --config Release`: fixed point at 39,609,824 bytes;
  - the Clang analyzer with the CI flags on `c_ast.c`, `c_ast_test.c`,
    `driver.c` and `ide.c`, with no reports.
