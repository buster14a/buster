## Attribution

A temporary, uncommitted diagnostic classified every FAST SPILL/RELOAD edit on
the unity compiler input by the machine opcode defining its value (x86-64,
`-march=native`, which avoids the `xgetbv` refusal of #1487):

| Defining opcode | Spills | Reloads |
| --- | ---: | ---: |
| `MOV_RR` (copy) | 80,859 | 88,291 |
| block parameter | 70,471 | 65,913 |
| `LEA_FRAME` | 40,777 | 10,750 |
| `LOAD_PTR64` | 8,144 | 4,697 |
| `ADD32` | 7,783 | 2,265 |
| `LOAD_PTR32` | 7,123 | 3,631 |

Most copy-defined spills whose source is a constant (`MOV_RI`) are
multi-definition join values (for example each `switch` arm assigning one
`String8` result): the mutable value's home write is the boundary contract,
not a missed rematerialization. `LEA_FRAME` values are different: an
address-taken slot is never coalesced, so the address is function-invariant
and every spill and reload of it is avoidable.

## Result

Same input (`ide cc -Isrc -Ibuild/generated -DBUSTER_UNITY_BUILD=1
-DBUSTER_INCLUDE_TESTS=0 -target x86_64-unknown-linux -march=native -g0
-fregister-allocator=MODE -c src/buster/apps/ide/ide.c`), base versus candidate:

| Mode | Spills | Reloads | Rematerializations | Object text bytes |
| --- | ---: | ---: | ---: | ---: |
| FAST base | 249,810 | 202,776 | 43,116 | 35,570,858 |
| FAST candidate | 212,750 | 194,700 | 51,317 | 35,312,421 |
| QUALITY base | 245,733 | 195,348 | 29,613 | 35,411,626 |
| QUALITY candidate | 208,781 | 187,959 | 38,035 | 35,159,685 |

FAST spills fall 14.8% and reloads 4.0%; QUALITY spills 15.0% and reloads
3.8%; text shrinks 0.72%. Boundary spills are nearly unchanged (103,068 to
102,148 FAST), so the removed traffic is eviction-driven. IR value counts are
unchanged: this is the issue's rematerialization item, not an IR reduction.

Unity compile wall time, FAST, three alternating runs: base 4,259 / 4,000 /
4,028 ms, candidate 4,040 / 4,032 / 4,024 ms. That is neutral within this VM's
noise; no compile-time or generated-program speedup is claimed. Matched 9700X
measurement, AArch64 execution and the full mode matrix were not run.
