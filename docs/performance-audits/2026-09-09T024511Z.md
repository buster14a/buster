## Coverage change

Incoming canonical block parameters have no defining instruction. The x86-64
selector left their place kind at NONE, and the AArch64 address helper refused
an absent instruction definition. Pointer joins and advancing pointers therefore
abandoned complete machine functions. Publish x86-64 block parameters as values;
on AArch64, distinguish instruction-defined locals from pointer-register bases.
Full MIR tracing also exposed storage-order-dependent verification in a newly
covered function. An unreachable predecessor was stored after its successor,
so the verifier incorrectly gave them separate roots. The verifier now finds
unreachable source strongly connected components, gives their entries a shared
synthetic root, and preserves joins between disconnected entries. Every member
of a closed source cycle is a conservative entry. Entry-reachable code remains
separate from dead predecessors. Permutation tests cover valid chains, invalid
multi-root joins, closed source cycles, and downstream loops with alternate
entries. Recompute reverse postorder from the actual entries after discovering
the source components, so dominator intersections always progress toward an
earlier parent. All 24 non-entry block permutations are checked for each of six
valid/invalid shapes; a capacity check bounds the extra root (145 assertions).
No production fallback or allocator default changes in this stage of #36.

The [five-function reproducer](2026-09-09T024511Z-pointer-fixture.c) covers a
pointer join, forward/backward walks, pointer swaps across a backedge, and a
sentinel scan. On the baseline, all five functions fall back in each of six
strict CLI legs (x86-64/AArch64 Linux, MIR_STACK/FAST/QUALITY). The repaired
selectors compile all five without fallback. The unit regression requires
pointer block parameters in its SSA input, verifies the selected MIR, checks
both frontend forms and all four allocators, and executes native scalar/pointer
cases against expected answers on supported unsanitized Unix hosts.

For the complete compiler translation unit, FAST and MIR_STACK fallbacks drop
from 63 to 6: all 57 INDEX fallbacks disappear. The remaining functions are
`os_flush_instruction_cache` (clear-cache opcode), `cpuid` and `xgetbv` (inline
assembly), and `object_mach_pageoff12_shift`, `jit_aarch64_pageoff12_shift`, and
`link_aarch64_pageoff12_shift` (encoding). A reduced unsigned-32 switch with
high-bit case values reproduces the encoding refusal. These remaining gaps and
other target-specific exclusions still prevent retirement of the canonical
backend; this coverage stage does not close #36.
