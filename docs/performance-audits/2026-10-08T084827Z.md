## Attribution

The previous audit (`2026-10-06T213453Z`) counted about 22k FAST spills that
flush dirty values before a parameter edge. A temporary, uncommitted
diagnostic split the pre-edge write-backs on this base. The workload was the
unity compiler (`ide cc -Isrc -Ibuild/generated -DBUSTER_UNITY_BUILD=1
-DBUSTER_INCLUDE_TESTS=0 -target x86_64-unknown-linux -march=native -g0
-fregister-allocator=fast -c src/buster/apps/ide/ide.c`).

| Pre-edge write-back of a dirty escaping value | FAST |
| --- | ---: |
| backward edge, value still used at or after the target | 9,730 |
| forward edge, join without a register contract, value live | 4,780 |
| forward edge, join without a register contract, last use before the join | 3,070 |
| forward edge, contract join, last use before the join | 6,057 |
| forward edge, contract join, live but not in the contract | 1,522 |

Only the contract-join rows are open to this change. Most stores whose last
textual use precedes the join lie inside loops, and a forward-only liveness
bound cannot drop them. Many of the rest are sources whose last use is the
edge copy itself.

## Change

- `machine_fast_parameter_contract` now also carries certain non-parameter
  values in the register they already occupy. A carried value is live,
  escaping, immutable, non-pinned and general, and the designated predecessor
  holds it dirty. `machine_fast_conform_edge_parameters` keeps it across the
  parameter publication. Carrying clean values as well gave 905 fewer spills
  but 524 more reloads. The dirty-only version gives 925 fewer spills and 112
  more reloads.
- `machine_fast_loop_floors` gives each block a floor: the first instruction
  of the lowest block reachable from it through backward edges. An escaping
  value is dead behind the current point when its last use is below that
  floor. Eviction (`machine_fast_owner_is_dead`) and edge write-back
  (`machine_fast_conform_edge`) then skip its store. A single function-wide
  floor dropped about 300 more stores. The per-block floor drops about 100
  beyond that. Allowing a last use at the edge copy itself drops about 800
  more.
