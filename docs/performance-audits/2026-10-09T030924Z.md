## Result

This change groups exact same-run analyzer invocations only when their
compile inputs and supported toolchain context pass a conservative stability
proof. The plan retains every selected database row. The worker executes one
representative per proven class, then reconstructs each alias row's log,
diagnostic status and failure accounting independently. Ineligible or changed
proofs keep rows on the per-row path. The result schema is V2; a complete
rollback restores the former V1 producer, and frozen V1/V2 evidence retains
its original meaning.

The rebased current-source census selected 182 Release rows, found 12 repeated
candidate classes, proved all 12, and planned 135 executions with 47 aliases.
The selected compile database has 364 Debug and Release entries. Planning took
8.090 seconds; the context proofs took 7.922 seconds. Full manifest and
producer provenance are retained in
[`evidence/2026-10-09T0238Z-issue3130/`](evidence/2026-10-09T0238Z-issue3130/),
including the compressed PLAN_V2 manifest and checksum files.

## Proof boundary

The proof applies to exact analyzer rows in one run. It is not a cross-run
cache or a reusable producer identity. Supported path inputs bind original
argv0, a bounded Clang symlink path and target, version/resource queries,
runtime-library contents and replayed loader resolution, positive dependency
content, include/config search-tree membership, the effective `-###` command,
and analyzer-mode preprocessing output. Dynamic date/time builtins remain
ineligible, including token-pasted and analyzer-conditional uses. External
checker configuration, PCH, AST merge, module, profile, overlay and plugin
inputs remain independent. The real Clang probes preserve `--analyze` while
selecting `-M` or `-E`, so `__clang_analyzer__` conditional includes and
preprocessing are visible. A normal `-Wreserved-module-identifier` cc1 warning
token is allowed while actual module-input options are rejected.

These checks rely on the caller keeping source, headers, search roots,
compiler, runtime libraries and configurations immutable from planning through
postflight. The proof does not lock files; a transient out-of-tree negative
lookup that changes and is restored between checks is not ruled out. Compiler
name, ELF format and version text do not authenticate a publisher. Hosted CI
must verify the actual `/usr/bin/clang` argv0 spelling; the local census used
direct `/usr/lib/llvm-21/bin/clang` because the hosted spelling was not
available in this environment.

## Source size and rationale

The native committed-revision report against `834d0fe665c1723af12df9a1ba44bb19a3670ba6`
measured build growth of 244,814 bytes, above the 32,768-byte ratchet; production

The generated baseline is intentionally not changed in this working revision.

revision; no baseline row was hand-edited. The current measured revision
reported the build growth as unacknowledged.
