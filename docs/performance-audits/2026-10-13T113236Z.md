## Workload

Every arm compiles the base revision's unity self-host source, from the base
worktree:

```sh
ide cc -Isrc -Ibuild/generated -DBUSTER_UNITY_BUILD=1 -DBUSTER_INCLUDE_TESTS=0 \
  -target x86_64-unknown-linux -march=znver5 -g0 -fsyntax-only \
  [-fc-ast-pilot] src/buster/apps/ide/ide.c
```

There are four arms:
- A: base, default flags;
- B: base with `-fc-ast-pilot`;
- C: candidate with `-fc-ast-pilot`;
- D: candidate, default flags.

`-c` arms swap `-fsyntax-only` for `-c -o <object>`. Callgrind ran with
`--cache-sim=no --branch-sim=no`. The `-g` objects were built outside
Callgrind.
