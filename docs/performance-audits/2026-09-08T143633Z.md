## Construction and ownership

The function-wide lexical blacklist has been replaced with per-owner eligibility
and actual lowered-place use classification. Ordinary calls, address-taking,
field/index expressions, aggregates beside scalars, adjusted array parameters,
ordinary goto (including irreducible joins), switch/fallthrough, scalar compound
literals and logical/conditional/statement-expression temporaries no longer
exclude unrelated locals.

Each admitted owner has a sparse `(block, owner)` current value. Reads before
predecessor completion create provisional block parameters. A nonrecursive work
queue completes incoming values after backedges are known. Single-predecessor
chains forward values without allocating incoming rows. Initialization is checked
before alias substitution: every journaled store RHS is a root, so copying an
uninitialized other owner cannot be hidden by an entry initialization. Missing
reaching definitions retain memory semantics rather than inventing zero.

A compact journal records declaration/read/write *sites*, source ranges and
original instruction anchors. It is not another IR. A retained SSA owner never
emits transient canonical LOCAL/LOAD/STORE rows. A rejected owner is restored
wholly at its original sites, including writes and reads before an eventual
escape; unrelated owners remain SSA. Restored loads become independent
definitions before any root compression. Value alignment, original instruction
IDs and extras, source locations, local IDs, debug names/types/scopes and C
lvalue/qualifier checks survive publication. Private expression temporaries do
not become named debug locals.

Indirect/non-local-jump calls, computed goto/label addresses, dynamic stack and
assembly keep the existing conservative function barrier. Narrow-normalizing,
volatile/atomic, static/TLS and cleanup-managed owners retain memory form.
Trivial parameters and unused parameter cycles are removed. The published CFG
includes predecessor edges for parameter-free blocks as well as parameterized
ones; disconnected empty label blocks are handled without forming an invalid
instruction pointer.

The conservative opcode summary now records LOCAL. Certified functions without
memory locals skip the shared pass's redundant discovery scan. Unknown summaries
remain conservative. X86 machine selection accepts supported vector block
parameters in the existing vector register class. Existing legacy memory-shape,
mutable-register and register-pressure assertions run explicitly through the
reference path; direct vector selection, verification and execution are also
covered rather than bypassed.

The current self-host source uses direct SSA in 4,202 of 4,467 functions, for
35,758 owners (8,975 private temporaries), eliminating 132,691 reads and 57,662
writes before canonical publication. It creates 451,079 provisional parameters
and removes 423,573; 1,841 journaled owners are restored. These are telemetry
counts, not a claim of zero remaining memory or zero native fallback. Shared
promotion still promotes eight further owners in this source.
