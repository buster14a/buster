## Change and invariants

Fixes GitHub #291 against main `719ba64e3022a0ae1db078ea97cb951a70ac02a0`.
The former fixed 16,384-slot index stopped inserting at 8,192 keys. Every
unindexed tag then required a type-table scan. The candidate doubles at half
occupancy and rehashes existing slots, preserving the stable header, oldest
identity, stale IDs and duplicate-scope markers across speculative rollback.
Qualified aliases are excluded both at insertion and when validating a reused
ID. Arena exhaustion/count overflow retains a correct lookup fallback; it is
represented separately from duplicate scoped tags. No new dependency or pass.

Initial slot storage is unchanged (512 KiB on this host). At 8,193 keys the
arena retains the original 512 KiB plus the new 1 MiB array; at 16,385 it also
retains a 2 MiB array. Old arrays stay allocated until the translation unit
ends. This bounded geometric storage is the explicit cost of eliminating
saturation scans. Duplicate tags and stale records still use the existing
semantic fallback; this does not claim constant-time scoped-tag lookup.

## Whole-frontend time and process memory

The retained collector runs the existing `ide bench` entry point from isolated
working directories containing a generated `tests/basic_c_operations.c`.
Each tag defines an `int` member and a const-qualified typedef. The zero-tag
control has one small function. Both ordinary Clang-built binaries receive
identical bytes. Each process performs one warmup and 30 measured passes
through preprocessing, parsing, semantics and canonical IR construction.
The entry point excludes source-file loading and shared-table prewarm from
its reported frontend duration. Process wall/CPU time and peak RSS are also
retained in the raw CSV. No generated-program runtime is measured.

Four balanced AB/BA pairs per population give 40 completed process records.
The larger timing sweep was interrupted after this complete five-population
set; no completed sample was dropped. The retained reproduction script limits
itself to these five measured populations. 16,384/16,385 remain covered by
deterministic operation-count tests, without a timing claim.
