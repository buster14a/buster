## Result

PR #856 now demonstrates a scoped default-lowering compile-time benefit on the
existing aggregate-ABI workload: **0.574% and 0.536% faster** in two fixed rounds.
Both paired uncertainty intervals exclude zero. The six standard workloads and
frozen-source unity compile remain inconclusive; this is not a general speedup.
The standard backend-pressure medians are slower in both rounds, but their
intervals span zero. This experiment does not establish performance equivalence.

The same additional workload establishes a normal-configuration benefit for
#854: **4.636% and 4.408% faster**. This supplements its earlier demonstrated
local-backed large-function improvement, recorded in
[the earlier #854 audit](https://github.com/buster14a/buster/blob/663a5fbbbcacf9aa1167780cbad3900bea139373/docs/performance-audits/2026-09-20T023154Z.md).

## Method and all results

Tests ran through `tailscale ssh david@benchpress`, on Ryzen 7 9700X Linux x86-64,
Clang 22.1.8, using the canonical TCC-bootstrap Release build. CPU 2 and
`/home/david/bench/host.lock` serialize timing. The powersave governor was left
unchanged. Exact commands, host settings, workload identities and every native
sample are preserved below. No observations were trimmed.

```sh
./build.sh bench_throughput run --baseline BASE --candidate CANDIDATE   --output OUTPUT --profile full --pairs 40 --warmups 2 --mode fast   --cpu 2 --machine-id benchpress --lock-file /home/david/bench/host.lock   --require-identical-output
```

Additional workload runs add `--workload macros --workload aggregate-abi
--no-guard`. No frontend/promotion flags are changed. The harness requires
`--no-guard` for this selected corpus; the broad built-in regression guard is
not the speedup criterion. Standard runs retain the guard.

Each workload has two fixed rounds of 40 adjacent pairs after two warmups.
Two-pair AB/BA blocks yield 20 geometric-mean candidate/base ratios. The estimate
is their median; bounds are the third and eighteenth sorted ratios. Each row's
distribution-free failure bound is `2*(1+20+190)/2^20`, assuming independent
blocks. The 36 rows reported here have union-bound simultaneous coverage of at
least 98.55% under that assumption. Serial correlation and host drift remain
limitations. Positive changes mean slower; marginal milliseconds are descriptive.
