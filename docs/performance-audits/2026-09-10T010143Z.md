## Scope and classification

Baseline: `ef99ec72cf0f17c8818a1d4b4c106fd5908b5eae`. This is a verified
prepared-plan consumer gap, not a known miscompilation or an accepted speedup.
`machine_x64_emit_exact_movabs` materializes each 64-bit switch case through
physical operands and the general exact writer, although MOV_RI variant 2
already has a metadata-proven GPR/immediate-patch table.

Consume that table without enlarging it. Validate the published shape and the
entire destination range, copy its two authoritative prefix bytes, and store
its eight-byte immediate. Zero and small values retain the ten-byte form;
ordinary MOV_RI's shorter alternatives are deliberately not selected. An
unavailable table keeps the checked metadata route. Invalid registers, null
storage and short/overflowed ranges fail before writing. Counters retain one
attempt followed by one success or failure. There is no new permanent table,
allocation, ISA requirement, or canonical/MIR row change.

The test-only private seam invokes the production helper and its original
metadata reference. The registered machine regression checks all sixteen GPRs,
fifteen boundary values, starts 0..17, capacities with 0..17 remaining bytes,
exact bytes, guards, failure atomicity and counters. It separately rejects
out-of-population registers, null storage, count greater than capacity and
UINT32_MAX. A preparation assertion prevents a silently unused optimization
from passing only through the old reference. Existing unsigned-switch tests
retain source-to-native coverage under all supported allocation modes.
`tests/x86_64_movabs_encoding_oracle.s` supplies 240 independent assembler
instructions, not data directives containing asserted instruction bytes.
