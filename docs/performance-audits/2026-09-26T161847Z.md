## Decision

Under `-g`, `machine_debug_values_build` records, per block, the value of
every debug local without a single stack place. For each block it reloaded
all U such locals and emitted all U: 2·U·B entries per function of B blocks,
whether or not any block carried per-block values.

The replacement decides once per function whether any block carries
`local_values`:

- **If one does,** the dense per-block reload stays as it was.
- **If none does,** which is the case for every function in the measured
  inputs, a block's entries can only come from its parameters. Only parameter-filled entries are
  written, recorded in a `filled` list, emitted and reset. That is three
  visits per filled entry.

The table is initialized once per function instead of once per block. The
emitted rows are unchanged, in the same order.

The code is in `src/buster/lib/compiler/codegen/machine.c`. The new counters
are `debug_value_blocks` and `debug_value_local_visits`.

`gen_debug.py` has three families, all compiled with `-g -c`:

- `locals N`: one function with N locals, each conditionally updated in a loop, so SSA gives each local block parameters and no single place;
- `locals_split N`: the same code as N/16 functions of 16 locals;
- `funcs N`: N small functions.

That term predates this change and is left to its own investigation.

## Equivalence and validation

- **Objects.** In census run 3, all 141 input × flag groups produced byte-identical objects across every ref, including this one. The `-g` inputs are the debug families and the `-g` self-host unit.
- **`machine_test_debug_values_differential`.** It now runs 96 cases, half dense (blocks with `local_values`) and half sparse, and compares against the reference rows.
- **`machine_test_debug_values_sparse_work`.** It requires exactly three visits per parameter-filled entry over 256 blocks.
- **Null blocks.** The dense pre-scan runs only when `unresolved_count` is nonzero, so a function with `block_count` set and no blocks never reaches it. `machine_test_debug_value_capacity` covers that case.
- **Local runs.** The full `ide test --ci=1` suite passes, except the two host-only `wide_vector_boundaries` assertions (#1292), which fail on main too. The self-host fixed point holds at 46,676,592 bytes.

## Limits

- A function whose blocks carry `local_values` keeps the 2·U·B dense path. None of the measured inputs has one: the self-host's 61,803 visits are exactly 3 × 20,601 parameter-filled entries.
- This PR adds two counters to `src/buster/lib/compiler/ir/ir_construction.h`, a retirement-bound source, so ordinary merge waits on the trusted integration writer.
