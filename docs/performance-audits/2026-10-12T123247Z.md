## Change and exactness

The `(` branch in `c_ir_constant_evaluate_impl` now calls
`c_ir_query_group_type_name(builder, index, close, &cast_type)` instead of
raising a raw type-name query over the interior. The existing gate and memo
settle impossible or already-probed groups without a query-machine frame.
A separate change rejects the exact `sizeof` keyword in
`c_ir_group_may_be_type_name`, before scope lookup. Positive probes and their
suspension/resume behavior remain in the existing helper. Scope-sensitive
`typeof` and lone unbound-identifier memo exclusions are unchanged.

Registered `c_test_constant_group_cast_probe` adds 130 assertions across both
canonical frontend forms. It fixes file/local-static initializer values for
numeric/nested/unary groups, parenthesized `sizeof`, built-in casts, narrowing
typedef casts, `typeof`, conditional expressions, a local typedef and an
object shadowing a typedef. Existing malformed-expression tests run unchanged.

## Host runtime workaround

CachyOS's installed glibc loader executes an AVX-512 instruction before
Buster starts; Valgrind aborts there with SIGILL and only 683 Ir. That failed
attempt is preserved as
[host-loader-failure.log](evidence/2026-10-12T123247Z/host-loader-failure.log)
and is excluded from all comparisons.

All successful ordinary object checks and Callgrind profiles use the same
isolated, signature-verified vanilla Arch package
`glibc-2.44+r50+g1848099f063e-1-x86_64.pkg.tar.zst`, without installing it.
`GLIBC_TUNABLES=glibc.cpu.hwcaps=-AVX512F,-AVX512VL` prevents AVX-512 IFUNC
selection. The native linker also inherited a v4 ISA-needed GNU-property note
from the host startup objects. Diagnostic copies remove only that note with
`objcopy --remove-section=.note.gnu.property`; every subject's `.text` hash
is identical before and after, recorded in provenance. Actual compiler code
was compiled for v3. The explicit loader prefix used in every successful cell
is:

```sh
valgrind --tool=callgrind --cache-sim=no --branch-sim=no   --callgrind-out-file=<capture>   <isolated>/usr/lib/ld-linux-x86-64.so.2   --library-path <isolated>/usr/lib <subject>-profile cc <common argv>
```

The retained profile script records complete argv and object hashes. Its
session root contains `subjects`, `glibc`, `frozen` and `profiles` directories;
place the script in that root to reproduce the same layout. Native correctness
checks use the ordinary trusted compiler and system runtime.
