## Removed work and storage

`c_ir_generic_selection` returned a predicted selected-expression type to its
sole prepared-call caller, which discarded it. The request and resume paths
each repeated that prediction. The candidate removes both predictions and the
unused output. It retains the semantic selection answer and selected-child
success check; ordinary child lowering produces the value and canonical type.
The predictor's fallback to s32 was not authoritative semantic validation.

`c_parse_generic_selection_one` previously requested one CTypeId per token
between the controller comma and final parenthesis. Only accepted typed arms
occupied that list. The candidate holds sixteen IDs locally and grows by
typed-arm count without another token traversal. Occupied IDs are copied only
at geometric growth, and the entire scratch region rewinds when the query ends.
No list pointer escapes in the retained answer, which holds token offsets.

For one successful resolution with A accepted typed arms, the source-derived
association-list requests are:

| A | Arena request bytes | Local stack bytes |
|---:|---:|---:|
| 1 or 16 | 0 | 64 |
| 17 | 128 | 64 |
| 33 | 384 | 64 |
| 65 | 896 | 64 |

The requested slot sum is less than 4A for larger lists. This bound excludes
other expression/layout machine scratch and is not a live-memory or RSS
measurement. Invalid selections can be retried by independent validators;
their cumulative request count is not the one-resolution bound. Growing a
large list adds occupied-ID copies; no net time saving is assumed from fewer
requested bytes. The existing quadratic compatible-association comparison is
unchanged.

`debug_fill_ir_type` independently copied the same nonempty canonical name
for `name` and `declaration_name`. The separate debug candidate copies it once
into owned model storage and shares the immutable bytes. For nonempty canonical
names, later type-symbol declaration-name replacement remains independent.
Empty canonical names retain their existing symbol fallback. Removed work is
one copy/request and name.length requested bytes per named canonical type,
plus any avoided alignment padding; no RSS/time quantity is inferred.
