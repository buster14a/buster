`2026-08-18f` (Linux x86_64, Zen 4 7940HS; **prewarm the closed GPR encoding
population, and reject gather-then-compress SIMD**). A unity self-compile
census finds about 1.36 million exact machine rows. Roughly 94.5% are single
exact forms; among those, 420,951 are GPR-only, 544,753 contain memory,
271,477 contain an immediate, 44,283 are relative, and only 76 contain vector
registers. The common register population is closed: each variable operand is
one of sixteen physical GPRs and current exact forms have at most two of them.

Serial metadata prewarm now asks the existing exact metadata authority for
every 16x16 member of each eligible form once. It publishes the result as
dense 16-byte records — fifteen architectural bytes plus one count — and adds
one compact table index to each prepared variant. The machine row worker reads
its one or two assigned register indices, performs one dense lookup, and copies
the prepared bytes. Fixed RAX/RDX/RSP operands, width and feature policy,
relocation absence, the 15-byte architectural bound, self-copy no-ops,
overflow handling, exact attempt/success counters, and the generic malformed
fallback all remain explicit. The metadata form/pattern transform remains the
sole byte authority; the machine layer only caches its immutable results.
Capacity is bounded to 64 tables. The trusted compiler grows by 640 bytes of
text and about 256 KiB of BSS rather than adding hot per-row facts.

A four-row AVX-512 packing kernel was implemented, disassembled, measured, and
reverted. Four arbitrary dense records were gathered into one 64-byte tile and
one real `vpcompressb` store removed their padding. The naive worker evaluated
four lane predicates at every row and regressed **+0.747%** instructions.
Gating on the first eligible lane reduced that to **+0.214%**. Finally, serial

**+29,480,888 (+0.2045%)**, with identical bytes. This closes arbitrary

SIMD encoder experiment must start earlier: classify a larger population into
homogeneous SoA commands, construct bytes in vector registers, and compact
afterward. Do not retry SIMD over already-encoded arbitrary records.
