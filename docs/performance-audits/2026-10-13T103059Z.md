## Mechanism and bounded fallback

`c_ir_ssa_finish_loops` previously prepared both the per-local read index and
forward-link forest for every function with loops. The header shortcut needs
only the write index. Keep that initial preparation; build the read index and
forest in `c_ir_ssa_finish_loop_exits` only once the general read walk spends
more steps than the function's blocks plus SSA events. Check between unresolved
reads: a stamped walk visits at most every block, so pre-activation work is at
most events plus twice the blocks. Successful preparation retains the same
closed-loop, no-read/no-write and forward-ancestry conditions. The CFG and
event journal are already final. An unavailable optional carve is attempted
once and retains the general walk, without marking lowering failed.

The frozen self-host input calls the optional preparation **zero times** (GDB
breakpoint census). The shallow four-loop test indexes zero blocks. At depths
250 and 1000, forward steps are **2301 / 8984**, and indexed blocks are
**752 / 3002**; the original `16 * depth` bound is unchanged. Forcing eager
activation with GDB makes the new shallow-no-setup assertion fail. A saturated
scratch-arena probe verifies that refused preparation allocates nothing,
records the attempt, and leaves lowering usable.
