## Mechanism and deterministic work

Two distinct non-self incoming roots witness a nontrivial parameter. The
simplifier watches their union groups, independent of the canonical chosen
representative. Union by rank moves only the losing group's witnesses.
A reader becomes due only when its witnesses meet or one becomes the reader;
both witness links are detached until evaluation, so no duplicate retry is
needed. The existing `(sweep, position)` heap preserves the first ordered
sweep position where elimination can become possible. Skipping a visit while
the witnesses stay distinct cannot replace that parameter or change any
later representative. Runnable roots still take precedence over dead roots;
self-only cycles keep their representative.

The C reproducer nests N `while(c)` loops around N calls to
`sink(c ? x : 1)`, followed by `x=x`. Source size is linear in N.

| N | Previous reader-list visits | New witness moves | New parameter visits |
| ---: | ---: | ---: | ---: |
| 512 | 265,724 | 513 | 2,048 |
| 1,024 | 1,055,740 | 1,025 | 4,096 |
| 2,048 | 4,208,636 | 2,049 | 8,192 |

The original reader counts came from the preceding fresh `40bc6d089300`
investigation; its complete direct-SSA section is byte-identical to this
baseline. Source, original counts and varying-depth/fanout controls are retained.
The new counts come from the separate instrumented implementation compiler.
All seven N=32..2048 objects match the frozen baseline compiler.

Parameter-free functions allocate no witness tables, parameter index or
live-parameter queue. The surviving parameter index is reused without a
second clear/rebuild; witness scratch expires before liveness. For the
straight-line control the new source census requests 16V scratch bytes and
12V clear bytes, with zero simplifier group rows. The old path unconditionally
included approximately 25V helper scratch bytes, 13V helper clear bytes and
another 8V parameter-table clear. These are logical requests/work, not RSS.

Dense ranking also proves whether every value and replacement is unchanged.
That case needs neither the second value-root scan nor a new operand pool;
retaining shared old slices is safe because no ID is rewritten and the
slices already belong to the output arena. Changed mappings keep the fresh
pool. Local metadata normalization remains unchanged. The 256-indirect-call
control reuses 1,542 operand slots with V=773. This population is rare in the
frozen unity input: **one identity publication / 29 operand slots** out of
6,557 finish calls and 1,785,687 operand occurrences. It is a targeted path,
not a basis for a unity improvement claim.

Predecessors use one checked array per function with edges while retaining
stable linked records, every CFG edge and sealed states. Each geometric
fanout control records one carve; the frozen unity diagnostic records 5,676.
Zero-edge publication makes no carve or alignment demand, and output refusal
is structured. No predecessor or validation edge is omitted.
