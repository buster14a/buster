## Disposition: do not adopt for speed

This bounded #51/#1701 experiment batches root rescan nodes, places the root
context on the stack, and reuses text-line wrapping/output storage after
materialization. It serves the default AST frontend. Correctness passes, but
the production self-compile shows no speed gain. PR #4197 retains the unmerged
implementation; it is not a significant compiler optimization.

Baseline: `e34df042d7a1d4820dd61c3d3ae39aee7e17a261`.
Implementation: `b47ac8427268c2c95a0a7b05b95b65e6e00cc554`.
Both production subjects use trusted Clang 23.1.1 Release, tests off,
`-O3 -march=native` and the normal C flags. Both compile the same frozen
baseline source and generated headers from the same input root. Commands,
binary hashes, host identity, observations and compressed validation logs are
in [the evidence directory](evidence/2026-10-14T112409Z/).
