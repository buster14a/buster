`2026-08-24T131758Z` (Linux x86_64, Zen 4 7940HS; **single-chunk machine
builder streams alias their live arena payload instead of flattening**).

Issue #544 follows the copy census in `2026-08-22T231635Z`, where
`machine_stream_flatten` remained the largest removable machine-stream copy.
The change is deliberately limited to `machine_function_builder_finish`: a
one-chunk stream aliases its payload when the finish arena is the builder
arena; a multi-chunk stream, or any finish into a different arena, keeps the
existing sequential flatten copy.

**Population before the change.** A temporary census in the trusted Release
`ide cc -c` compile of the unity `src/buster/apps/ide/ide.c` saw 3,899 selected
machine functions. Every function had nonempty instruction, virtual-register,
and block streams. The single-chunk counts were:

    stream                 one chunk       multi chunk       one-chunk rows
    instructions            3,491 (89.5%)       408             503,161
    virtual registers       3,728 (95.6%)       171             530,900
    blocks                  3,877 (99.4%)        22              92,591

The one-chunk payload is already contiguous: 12.08 MB of instructions,
8.49 MB of virtual registers, and 2.96 MB of blocks. Edges, block parameters,
and edge-copy-source streams were empty in this workload. The census was
temporary and is not part of the compiler.

**Implementation.** `machine_stream_materialize` checks exact arena identity
and `first == last`, returning `chunk + 1` for a live one-chunk row span. The
builder's arena remains live through encoding, as required by the returned
`MachineFunction` lifetime; cross-arena finishes allocate and copy so callers
can release the builder arena. The shared `MACHINE_BUILDER_CHUNK_BYTES`
constant remains the sole chunk-size invariant.

**Paired measurement.** Eleven order-fixed pairs ran on CPU 5 with
`perf stat`, each binary compiling the same unity source with the same output
path. The baseline disabled the alias predicate; the candidate enabled it.
Generated objects were byte-identical (40,369,704 bytes). Candidate deltas
against baseline, paired per run, were:

    instructions             median -1,944,559   11/11 lower
    branches                 median   -233,517   11/11 lower
    branch misses            median   -135,003    8/11 lower
    cycles                   median -50,409,796    7/11 lower (noisy)
    L1d loads                median -5,458,658    7/11 lower
    L1d load misses          median   -819,633    9/11 lower

Instructions were lower in every pair (mean -1,949,073); cache and cycle
counters are recorded for context and are not used as the gate.

**Verification.** The Release `ide` target and Debug `ide` target both build
with the custom compiler. Focused alias, multi-chunk ordering, and cross-arena
release assertions pass. After all concurrent edits settled, the combined
Release suite passed 309,750/309,750 assertions and 39/39 modules, and the
self-host stages remained byte-identical.
