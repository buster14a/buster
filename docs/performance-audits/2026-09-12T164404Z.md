## Implemented behavior

- AArch64 vectors through sixteen bytes use ordinary canonical pair edges,
  including loop rotations and calls with live vectors. Pair participants own
  storage for both limb reads; ABI transfers retain the original exact width.
  Existing frame-vector fixtures are unchanged.
- Binary32/64 widening to binary128 uses scalar MIR normalization, rebiasing
  and payload/sign transport. It quiets signaling NaNs with a consumed FP row
  and preserves finite subnormals under flush-to-zero. No direct emitter,
  soft-float dependency or new instruction pseudo is introduced.
- signbit reads the original representation without floating conversion.
  This fixes spurious exceptions from observing signaling NaNs and wide values.
  New independent host observers check bit images and floating state. Existing
  created-NaN input remains in the strict matrix.
- Native Linux AArch64 tests swap compiler producer/consumer roles and exercise
  all rounding modes, default-NaN/flush state, preserved exception flags and
  adjacent-byte sentinels. Other targets retain object checks.

The new pointer-based binary128 signbit input is rejected by the frozen direct
backend's LOAD gate. Its twelve NONE observations are retained as explicit
failed-reference controls; MIR success uses independent expected bits. It is
not an exclusion of a previously supported input.
