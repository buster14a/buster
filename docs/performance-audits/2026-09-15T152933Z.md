## Workload and setup

Stage-1 unity self-compile, the workload
[#646](https://github.com/buster14a/buster/issues/646) reports:

```sh
./build/Release/ide cc -Isrc -Ibuild/generated -DBUSTER_UNITY_BUILD=1 \
    -DBUSTER_INCLUDE_TESTS=0 src/buster/apps/ide/ide.c -lm -o ide-stage1
```

Both compilers are Clang-built Release `ide` binaries from the same tree, so
the only difference between them is the change under test. Runs are
interleaved (before/after, default/`-g0`, six rounds) and reported as user
CPU time, because wall time on this shared container swings by seconds
between identical runs. **This is not the 9700X bench host the issue's
completion criteria name**, and `perf` is unavailable here, so there is no
sample profile in this audit: the A/B below and the stage bypass are the
measurements.

## Where the remaining cost is

An env-gated bypass compiled into a throwaway binary (not committed) staged
the recorder. Same workload, user CPU, best of two:

| Stage | s | delta |
|---|---|---|
| `-g0` | 2.86 | — |
| debug info on, recording skipped entirely | 2.99 | 0.13 (debug value tables, DWARF emission) |
| + per-function index built | 3.06 | 0.07 |
| + spans resolved and reference timelines replayed | 3.32 | 0.26 |
| + seeds emitted | 3.33 | 0.01 |

That bypass predates the two cost fixes that followed it — skipping runs of
block starts that cannot change a tracked register's state, and indexing only
the virtual registers a debug value names — which together removed about half
of the replay column. The residue is the per-function index (O(rows + edits +
marks), paid once per function whatever the debug value count) and the
replays themselves.

## Output equivalence

Recording is a rewrite of a byte-identical contract, so equivalence is the
result, not a side note. The before and after compilers were each asked for
`-g -c` objects of the stage-1 translation unit (about 1.5M lines after
preprocessing) in every allocator mode:

| Allocator | Object | Result |
|---|---|---|
| default (`fast`) | 46,629,496 bytes | identical |
| `-fregister-allocator=quality` | 46,376,328 bytes | identical |
| `-fregister-allocator=mir-stack` | 57,890,976 bytes | identical |

`./build.sh test_self_host --config Release` keeps the fixed point
(`SELF_HOST fixed_point bytes=40381096`), `test_all` passes in Release and
Debug, and `test_mode_matrix --config Release` passes all 24 legs.

## Seed storage

Seed arrays now grow with what recording emits instead of reserving
`debug values x (rows + 1)`. On this workload that bound reserved 357M seeds
(20 GB) to emit 167k. The regression fixture records a function whose bound
would be 41.7 GiB — past the 32 GiB translation-unit reservation that used to
abort the compile — and it now completes inside a normal arena.
