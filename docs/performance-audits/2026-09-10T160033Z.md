## Exit threshold and outstanding work

The retirement threshold is zero native production fallback across supported
targets and previously successful fixtures, with strict canonical/MIR
validation, clean differential results and real target execution where an ABI
or unwind format changes. Object creation alone cannot accept such changes.
Unsupported diagnostics must not replace formerly supported native programs
merely to reduce a fallback count.

Outstanding areas include AArch64 Windows ABI/unwind selection; x87/wide-float
and wide-integer coverage; 128-bit atomics; general inline assembly; Darwin
variadic/TLS handling; and public AAPCS64 `va_list` interoperability (#360).
The existing private four-word `va_list` is not an acceptable public ABI.
The follow-up also adds generated UMULH selection, 128-bit unary/variable
shifts and verifier-correct synthesized definitions, with separate regressions.

No compile-time, peak-RSS, generated-code-size or runtime budget is claimed
met by this checkpoint. Those final comparisons need matched configurations,
immutable inputs and an agreed workload/budget before the direct reference
is removed. The pinned source and repository differential harness preserve
a reproducible reference while that work proceeds.
