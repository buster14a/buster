## Decision and evidence class

Skip `c_parse_word_bits_compute` and spelling materialization for known nonword
tokens on the fallback path of `c_parse_word_bits_token`. Reuse the existing
`c_token_may_spell_word` predicate. This removes a whole string-comparison ladder
from those queries rather than changing its branch prediction hints.

The interned-symbol path remains first and unchanged. Without that path,
IDENTIFIER and INVALID hand-built rows still compute from spelling; EOF,
punctuation, numbers, literals, newline and pragma markers answer zero.
Each caller retains its existing GNU/C23 mask and qualifier writes.

This is a source-confirmed avoided-work candidate, **not a measured hardware
branch-miss reduction or speedup**. No compiler, benchmark or profiler was run
on the laptop or benchpress/9700X in this pass. Fresh PMU attribution remains
pending; old counts are not transferred to the current source.
