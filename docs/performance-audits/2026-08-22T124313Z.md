- **Scalar float bodies (13 CAST + 8 BINARY + 1 UNARY to 0).** The
  FARITH/FCMP analog `2026-08-11a` named, in the x86-64 bit-image model:
  values stay IEEE images in general registers, each row rides V0/V1 —
  the canonical emitter's own scratches, outside every allocatable file,
  so no clobber mask and no new register class. The a64 shape is simpler
  than x86-64 at every turn worth recording: fcmp's flag encoding gives
  unordered-false C semantics directly (MI/LS/GT/GE — no parity repair),
  ucvtf/fcvtzu convert unsigned 64-bit in one instruction (no branchy
  sequence, no RCX-analog scratch), and float negate is the canonical
  integer-side sign-bit XOR, needing no row at all. Twelve new opcodes,
  all in the scheduler's float-state chain. Coverage 166 to 187.
- **Scalar stack arguments (signature rejections 21 to 19, CALL 4 to 3).**
  Arguments past the eight X or eight V registers: the caller writes
  eight-byte images into a fixed outgoing area pinned at the frame
  bottom (the Win64 model; the target-neutral placement already carried
  it), and the callee reads them back through a new LOAD_INCOMING row at
  `[x29, 16 + part * 8]`. One a64-only wrinkle: the shared placement pins
  the area at `frame_size`, but the a64 frame area extends past that by
  the callee-saved save words, so the encoder addresses this one slot
  SP-relative. Placement mirrors the canonical simulation exactly —
  including its quirk that integer overflow does not close the file for
  a later narrower argument. Aggregate/HFA stack arguments stay
  canonical. Coverage 187 to 190; the class is closed, and the residual
  signature mass is variadic definitions, vectors, and indirect
  arguments.
