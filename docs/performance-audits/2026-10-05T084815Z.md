## Decision and scope

PR [#2622](https://github.com/buster14a/buster/pull/2622), owning issue
[#2672](https://github.com/buster14a/buster/issues/2672), is qualified here for
bounded correctness and observed code quality. This receipt establishes neither
compiler speed nor a 0.5% throughput non-regression admission. The required
six-pair compiler comparison has **NO DETECTABLE DIFFERENCE** with a wide
interval; its geometric-mean cross-check suggests slower and is retained below.
Do not reinterpret an inconclusive comparison as performance equivalence.
No dedicated Ryzen, Zen 4/5 physical gate, generated-program runtime performance,
cache-traffic or latency-admission result is claimed.

The change records a nearby constrained consumer's register as an advisory hint
and selects it only from an already-free, class-constrained candidate set. It
never evicts for a hint or overrides fixed, tied, pinned or reserved constraints.
Mutable values, cross-block definitions, invalid definitions, distant uses and
callee-saved-preferring values retain the existing conservative behavior.
QUALITY retains its existing strict acceptance comparison after FAST reruns.
The preparation converges the added picker through one final return and updates
[the owning machine guide](../agents/machine.md). No new dependency or global
cost model is introduced; generated retirement identities remain integration-owned.
