## Disposition

On current main, A shows **no detectable compile-time difference** from C,
within about ±0.04%, in a run with no drift warning. Together with the
earlier B result (no detectable difference, ±0.37%), neither alternative
improves compile throughput on the trusted Clang-built compiler. **Keep C**:
it is the production code and the smallest binary. Branchlessness is not
counted as a reason; C stays because nothing beats it. PR #3118 changes no
production source.
