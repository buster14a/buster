## Final implementation and preserved policy

- Dense sets remain through 2^18 words per plane. Larger solved populations
  use immutable eight-byte binary nodes, shared unchanged subtrees and zero/full
  sentinels, with iterative reverse-CFG propagation and fixed-depth stacks.
  Node allocation is bounded at 64 MiB. Exhaustion rewinds unpublished nodes
  and uses the prior dense solve, preserving exact facts.
- The established 2^22-word block-by-value **analysis-work budget remains**.
  It is checked before allocating/filling the value index. The remaining size
  discontinuity is an intended throughput boundary; sharing does not authorize
  extra analysis for better generated frames. The broad #4009 home-coloring
  slice remains with its separate owner.
- Single-block, empty and over-budget populations publish no unused index.
  Call-free functions allocate/fill no next-call table; the consumer treats its
  absence as no call, retaining function-wide crossing semantics otherwise.
- Vector presence and tracked count share the completed escape reduction.
  The backward gen/kill instruction scan remains required: escape identities
  become final only after defining blocks are known (#1722). No extra persistent
  occurrence stream or naive forward/backward fusion is claimed.
- Backward-edge spans already have nondecreasing source ends. Each incoming
  interval merges the overlapping suffix of the union, so every span is pushed
  and popped at most once. The sort, log-level copies and sort scratch disappear.
- Dense/shared query eligibility is cached at block setup; dispatches without
  one destination still have no live-in query. This is not an independently
  attributed whole-compiler speed claim.
