`2026-08-18o` (Linux x86_64, Zen 4 7940HS; **classify allocator lanes once
and make the machine-row append path typed**).  The post-`18n` profile moved
the center of native codegen back to selection and FAST placement/prepass:
the unity self-compile contains 1,208,662 fixed 24-byte machine rows and
1,003,942 virtual-register rows.  Two common paths were still treating those
populations as unrelated scalar events.  Every instruction append reloaded a
generic byte-stream descriptor and multiplied by its element size, and the
FAST prepass decoded every machine operand a second time after definitions
were known merely to decide cross-block escape state and rebuild CFG facts.

`MachineFunctionBuilder` now keeps a typed instruction cursor/end pair.  The
hot append is one pointer bump plus the fixed row store; the existing 16 KiB
chunk allocator remains the cold boundary, and the existing final flatten
still produces the public contiguous array without gross reservation.  FAST's
first prepass walk records each value's use-block state in a transient packed
`u16` SoA (`none`, one block, or multiple blocks).  One dense reduction marks
escapes after definition blocks are complete, so the second CFG walk visits
only each block's terminator.  Functions too large for the 16-bit projection,
or malformed machine rows with block references outside terminators, retain
the original all-row path.  This removes repeated interpretation without
assuming layout-order definition dominance.

The allocator's free-register query is also the first direct SIMD kernel in
this layer.  On AVX-512 targets it compares sixteen contiguous `u32` owner
lanes to the all-ones free sentinel with one 512-bit byte equality, compacts
the four-byte results into a sixteen-bit lane mask, and intersects the active
candidate mask.  Wider files consume the same kernel in sixteen-lane chunks;
the old bounded scalar `ctz` walk remains the non-AVX-512 fallback.  The mask
compaction was exhaustively checked over all 65,536 possible lane masks.

Seven same-source, CPU-pinned, non-multiplexed instruction pairs are byte-
identical and reduce the median from 11,460,894,401 to 11,359,877,631,
**-101,016,770 (-0.8814%)**; all paired deltas lie between -100.63 M and
-101.13 M.  Branches fall 2,173,255,250 -> 2,151,239,413 (**-1.0130%**),
branch misses fall 27,200,314 -> 26,576,912 (**-2.2919%**), and L1d loads
fall 4,096,446,931 -> 4,070,825,197 (**-0.6255%**).  The transient use-block
projection raises median L1d misses 130,619,512 -> 131,556,142
(**+0.7171%**); packing it to sixteen bits reduced both that cost and another
~7 M instructions versus the initial `u32` form.  Twelve alternating cycle
pairs are noisy (7/12 favor the candidate) but reduce the independent median
4,423,058,276 -> 4,406,149,309, **-0.3823%**.  Isolated instruction gates
attribute about -0.189% to the AVX-512 free-lane kernel and another -0.09% to
the typed builder cursor; the pass reduction supplies the majority.
