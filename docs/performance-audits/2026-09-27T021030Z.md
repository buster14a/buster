## Decision

Two byte-identical production changes on the native object path, justified
by exact counts rather than timing:

1. **ELF64 writer.** `object_elf64_plan` counts relocations per section,
   locals and both string tables, and lays out every range with checked `u64`
   arithmetic. `object_elf64_emit` stores each byte once through bounded
   cursors. On the stage-1 self-compile (`-g0`):
   - relocation visits fall from **1,628,009 to 187,695** (26.0 to 3 per
     relocation);
   - symbol visits fall from 144,536 to 61,944 (7 to 3 per symbol);
   - reserved image bytes fall from 42,707,964 to exactly the output,
     **38,057,760**;
   - patched bytes fall from **1,998,832 to 0**;
   - bytes left in the caller's arena fall from 42,956,494 to 38,057,760.

   The priority split no longer copies or rescans the relocations: it records
   where each grouped initializer entry went, and the plan and emitter place
   each relocation as they reach it, so every relocation is still visited
   exactly three times. The old split took one relocation pass per group. On
   2,000 constructor/destructor priority pairs that takes relocation visits
   from **217,071,336 to 72,138**. The plan refuses section counts at
   `SHN_LORESERVE`, 32-bit string-table overflow, `u64` overflow and
   arena-exceeding files, and the split refuses a group count past the same
   section limit before it takes any memory. The old writer truncated the first
   two silently and aborted on the last.
2. **Machine encoders.** They write straight into the module code buffer when
   their worst-case budget fits. On stage-1, all 21,382,846 machine-code bytes
   are now encoded in place instead of being copied from encoder scratch. The
   75,925,328 bytes of per-function budget buffers are no longer requested.

Design record and staged plan: the object-emission issue linked from the pull
request.

  `ide cc -Isrc -Ibuild/generated -DBUSTER_UNITY_BUILD=1 -DBUSTER_INCLUDE_TESTS=0 -g0|-g -v -c src/buster/apps/ide/ide.c`.
- **Container:** Clang 18.1.3, GNU binutils 2.42, LLD 18.1.3, with the
  hosted-Clang bootstrap exception (no TCC on the host).

Counters:

- **Committed.** `ObjectWriteStatistics` counts every loop iteration over an
  input array and every store into the image; `ide cc -v` prints it as
  `OBJECT_WRITE`. `CodegenStatistics.machine_code_bytes_{in_place,copied}` is
  printed as `CODEGEN_EMIT`.
- **Old ELF path.** Measured with
  [`reference_probe.py`](evidence/2026-09-27T021030Z/reference_probe.py): a
  disposable one-line edit that routes `-c` ELF output through the frozen
  previous writer, which test builds keep as a differential oracle. That writer
  is instrumented the same way. Its objects equal the base compiler's byte for
  byte.
- **Upstream of the writer (base only).** Measured with
  [`census_probe.py`](evidence/2026-09-27T021030Z/census_probe.py), an
  anchor-checked disposable counter patch applied to a throwaway base
  worktree. Its objects also equal the base compiler's.
- **Harness.**
  [`object_emission_ab.py`](evidence/2026-09-27T021030Z/object_emission_ab.py)
  generates the adversarial inputs and runs the corpus identity, the ledgers
  and the independent-tool checks.
