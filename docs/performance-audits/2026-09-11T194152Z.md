## Removed state and equivalence

The descriptor's unused name, speculative rematerializable/bundle/expands
attributes, cost classes, and FLAGS/NZCV resource bits are removed. The sole
live resource-mask predicate becomes `implicit_vector_state`; the sole live
schedule-class predicate becomes `schedule_barrier`. Operand roles, constraints,
clobbers, memory effects and real flag attributes retain their exact values.
Reserved padding retains every live descriptor offset.

The census compiles the actual initializer macros and `machine_opcode_infos`
from each source tree, then appends the corresponding
[baseline probe main](evidence/2026-09-11T194152Z/baseline-probe-main.c) or
[candidate probe main](evidence/2026-09-11T194152Z/candidate-probe-main.c).
To reproduce, extract from the first `#define MACHINE_OPERAND_USE_GENERAL`
through the closing `};` of `machine_opcode_infos`, prepend
`#include <buster/lib/compiler/codegen/machine.h>`, append the probe main and
compile with that revision's `src` include path using
`clang -Isrc -O2 -fwrapv -fno-strict-aliasing -funsigned-char`.

Every one of the 246 normalized descriptor rows matches byte for byte:
[baseline](evidence/2026-09-11T194152Z/baseline-descriptors.csv),
[candidate](evidence/2026-09-11T194152Z/candidate-descriptors.csv).
Columns are opcode, clobber mask, active attributes, operand count, four
operand descriptors, tie, early clobber, fixed mask, four fixed registers,
memory effect, and combined barrier/vector predicates. This independent
census supplements the unchanged frozen whole-opcode scheduler oracle.

The verifier adds these checks to its existing virtual-register walk. There
is no additional pass, per-instruction projection, array or allocation.

The ownership document now inventories every shared production record's
