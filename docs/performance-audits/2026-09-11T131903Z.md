## Defect and recovered correction

On unmodified main, both `run_perf_stat` in `branch_miss_survey.py` and
`measure_budget` in `cache_miss_survey.py` accepted complete numeric counters
from a `perf` process that returned exit 1. This was reproduced using
`unittest.mock` process results, not a claimed hardware-counter collection.
The reproduction supplied valid counter lines followed by `link failed`;
both functions returned apparently valid measurement dictionaries.

The recovered scripts reject nonzero process status and incomplete,
unsupported or uncounted event sets. Cache captures also reject missing or
empty output, remove stale captures before recording, and discard stale
report/budget files before a new measurement attempt. Keep the original
parser/address-mapping checks and the additional failure-path self-tests.
Stage-1 command construction includes `-lm`, verbosity and source metrics;
the branch survey respects its selected `--binary`. Repetitions must be
positive. No new measurement system or production compiler pass is added.
