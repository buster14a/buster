## Workload

The arms compile the base revision's unity self-host source from a pristine
checkout of the base:

```sh
ide cc -Isrc -Ibuild/v3/generated -DBUSTER_UNITY_BUILD=1 -DBUSTER_INCLUDE_TESTS=0 \
  -target x86_64-unknown-linux -march=znver5 -g0 -fsyntax-only \
  [-fc-ast-pilot] src/buster/apps/ide/ide.c
```

The four arms:
- A: base, default flags;
- B: base with `-fc-ast-pilot`;
- C: candidate with `-fc-ast-pilot`;
- D: candidate, default flags.

`-c` uses the same input with `-c -o`, at `-g0` for instructions and at `-g0`
and `-g` for object identity. Callgrind ran with `--cache-sim=no
--branch-sim=no`. Per-line self costs and call costs come from the Callgrind
`fl=`/`fn=`/`calls=` records.

- **Element ends that nobody reads.** A brace-enclosed aggregate element

  ([#3667](https://github.com/buster14a/buster/pull/3667)) reads the unit's
  delimiter pair table when every delimiter nests, and otherwise falls back to
  the same-kind scan with the same clipped answer.
- **Repeat walks.** The 579 re-walks run at a different time from inference,
  and with element checks that inference does not make. Merging them is a
  design change. It is not attempted, and it stays open.

## The change

All of it is in `c_parse.c`, on the default path, with no tree:
1. **Braced elements end at their `}`.** The brace-enclosed branch runs
   before the end scan, and the end scan runs only for the other elements.
2. **The pair table.** `c_parse_initializer_brace_close` answers the list's
   own `}` and each braced element's from the position index's pair table
   when `delimiter_mismatch_count` is 0. Otherwise it runs the brace-only
   scan as before. It does not add to #3667's tag-scan counters.
3. **A set test in the end scan.** `c_parse_initializer_value_end` passes
   every token outside the seven delimiter and comma punctuators with one
   `c_punctuator_in_set` test.

Debug and sanitized builds (`BUSTER_REFERENCE_CHECKS`) run the brace scan
behind every table answer, and the end scan behind every braced element, and
check that they agree.
