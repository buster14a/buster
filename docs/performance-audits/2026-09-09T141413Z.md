## Coverage contract

Base `bf9afdbe886821aecc9be787075b7cb84c9bdcd1` is the merged tree of
[PR #354](https://github.com/buster14a/buster/pull/354), identical to its locally
and remotely tested source. Full-compiler MIR fallback was two functions:
CPUID and XGETBV literal inline assembly in `src/buster/lib/x86_64.c`.

The new x86 selector recognizes complete 32-bit pure output sets, separate
fixed inputs (including numeric/named ties), and memory/cc clobbers. CPUID
inputs share one constrained row, fixed to RAX/RCX; its RAX/RBX/RCX/RDX
clobbers drive liveness and callee-save preservation. XGETBV consumes RCX,
clobbers RAX/RDX, and retains the existing XSAVE compile-target gate.

Each row stores the architectural results as zero-extended eight-byte values
in a private frame object. Ordinary machine loads/stores then publish outputs
in source operand order, including indirect output places. This avoids
serial physical input moves and mutable result virtual registers. The
verifier checks the complete result-frame capacity; the encoder checks it
again before writing. Both operations are memory barriers in the scheduler
and conservatively define flags for accepted cc clobbers. Their exact forms
are prepared by the shared metadata cache before worker use. The two new
opcodes and expansion recipes append to the existing identities.

Partial-width, read/write, partial-output, additional-clobber and unrestricted
assembly forms retain their existing fallback. This stage achieves zero
fallback in the full x86 compiler; it does not retire the direct backend or
close #36's broader platform/ABI/assembly and performance-budget criteria.
