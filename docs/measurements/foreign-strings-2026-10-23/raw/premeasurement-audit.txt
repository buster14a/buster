Frozen campaign premeasurement audit, 2026-10-23

The baseline and candidate benchmark sources are byte-identical. The source
delta is only foreign_strings_link.c: eliminate duplicate symbol entry lookup,
skip entry searches for zero-addend named fixups, and check nonzero addends
against one source entry's relative bounds.

Each process requests all 24 rows: 3 counts x 2 input cases x 4 variants. Each
variant has one warmup and 11 measured links. The 100 ms condition also runs
before warmups, so at least 28.8 seconds of each conditioned process lies in
conditioning, outside the per-link timer but inside process CPU measurements.
Explicit --order reverses variants for repetition 2. The helper takes COMMAND
directly, with no -- separator. Every invocation obtains its own shared lock.

Interpretation fixed before any timing result was available: require repeated
whole-link improvement beyond observed process ranges. Flag ANY negative
control slowdown with disjoint process ranges as blocking retention pending
review; report smaller and overlapping changes without claiming equivalence.
No arbitrary percentage materiality threshold is introduced. Whole-link and
phase evidence, as well as candidate-versus-baseline and pooling-versus-no-pool,
remain separate.

The whole timer includes name arena reservation, resolver, conversion, optional
merge, symbol entry lookup/writer wrapper and cleanup. Retained-arena is the
last successful sample's summed arena lengths before release, not reserved
capacity or peak RSS. Input generation, unlink, conditioning, execution and
complete byte validation are outside the whole timer.

Frozen unique-output validation is internal only within each merge state.
External comparison must additionally establish all-four-variant unique
identity and cross-process/cross-binary identity. All original ET_REL files,
output files and per-process receipts will be retained.

Read-only assembly audit confirms two symbol-entry searches become one and
two named-fixup searches become zero for zero addends or one for nonzero.
foreign_strings_apply shrinks from 3072 to 2916 bytes; both retain six pushes
and 88 bytes of local stack allocation. This is not spill elimination. The
generated named ABS64 zero-addend workload directly exercises the shortcut;
it does not prove nonzero-addend or section-relative performance.
The scalar conditioning hot loop uses integer operations; clock arithmetic
uses XMM/VEX instructions. No AVX-free or power-state-mechanism claim is made.

Remote compiler/archive/helper hashes match the frozen protocol. The host is
Ryzen 7 9700X with CPU 2 online and performance governor; CPU 10 was offline at
the pre-campaign capture. /tmp output is tmpfs; both build trees are btrfs.
Compiler is Clang 23.1.1 with captured -O3 -march=native flags. No host settings
or source trees were changed. Full provenance and original assembly retained.
